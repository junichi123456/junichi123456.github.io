## 0. 目的と全体の流れ

1. 公開構築（`data/known_teams.json`）から、よく使われる**並び（軸）**を 11 個に確定する（§2）。
2. 自分の選出に**選出規則**（§3）を、対戦中の自分の行動に**行動規則**（§4）を足す。

4. 結果を `pokechamp/logs/CORES_R9.md` にまとめる（§6）。

対象外: Star Crusade（ルートの `index.html`・`starcrusade/`）、`game_watch.py`、OCR 関連（`glyph_ocr.py`・`font_probe.py`・`hpdigits.py` など）、`team.py` の書き換え、`data/*.json` の中身の書き換え。

## 1. 前提（コードで確認した事実）

### 1.1 R9 を読み込む手順（team.py は変えない）
- `refine.apply_party(party)` は `_BASE_SPECIES`（初回呼び出し時の `battle.TEAM` の種族＝`team.py` の旧パーティ）と種族が一致しないと assert で止まる。R9 は種族が違うので、そのままでは読み込めない。
- `battle.MY_TYPES`（相手の型推定 `infer.best_set` に渡す自分のタイプ）は import 時に `team.py` から作られ、`apply_party` では更新されない。
- そこで `core_test.py` の起動時に、**プール（fork）を作る前に**次を行う。
  ```python
  party = refine.load_party(9)
  refine._BASE_SPECIES = [p['species'] for p in party]
  refine.apply_party(party)
  battle.MY_TYPES = tuple(tuple(m.types) for m in battle.TEAM)
  refine.teams()          # B.KNOWN_TEAMS に known_teams + new_teams_m6b を入れる
  ```
  Linux の fork ではワーカーがこの状態を引き継ぐ。Windows（spawn）でも同じ結果になるよう、ワーカー関数の先頭でも同じ処理（`_init_r9()`）を呼ぶ。冪等にする。

### 1.2 engine の行動の表し方（engine.py / search.py）
- 行動は `E.actions(st, i)` が返すタプル。技は **`('m', 技ID, メガフラグ)`**（3 要素。例 `('m', 'stealthrock', False)`。メガ可能な個体は `True`）、交代は **`('s', j)`**（`j` は `st.sides[i].mons` の添字＝選出順の位置。先発 0、控え 1・2）。反動は `('m', 'recharge', …)`。
- 技 ID は Showdown 形式。日本語からは `dex.move_id('ステルスロック') == 'stealthrock'`。本仕様で使う ID:
  ステルスロック `stealthrock`、どくどく `toxic`、トーチカ `banefulbunker`、まとわりつく `infestation`、じこさいせい `recover`、あくび `yawn`、じしん `earthquake`、なまける `slackoff`、なみのり `surf`、クイックターン `flipturn`、みちづれ `destinybond`、アーマーキャノン `armorcannon`、トリプルアクセル `tripleaxel`、つららおとし `iciclecrash`、こおりのつぶて `iceshard`、とんぼがえり `uturn`。
- 上書きする行動は、必ず `E.actions(st, 0)` が返したタプルの中から選ぶ（`a[0]=='m' and a[1]==ID` で探す）。メガフラグはそのタプルの値をそのまま使う。
- 倒れた後の入れ替え、とんぼがえり・クイックターン後の交代先は、ターン中に `E.step(..., chooser=S.chooser)` の `chooser(st, side, opts)` が選ぶ（`opts` は控えの添字）。`a0` では決まらない。
- 場の状態: 相手側のステロは `st.sides[1].cond.get('stealthrock')`。状態異常は `m.status`（`'psn'`・`'tox'`・`'slp'` など、無しは `''`）。能力変化は `m.boosts['atk']` など。ばけのかわは `m.ability == 'disguise'` かつ `m.busted is False` のとき残っている（`True`・`'done'` は剥がれた後）。タイプは `E.Battle(st).types(m)`。メガ後かどうかは `m.mega_form is not None and m.form is m.mega_form`（`m.name` はメガ後も元の名前のまま。ログにも「グソクムシャ」と出る）。メガ前でも `m.can_mega` と `m.mega_form.types` で、メガ後のタイプが分かる。
- `S.best_damage(st, i)` は「i 側の場のポケモンが今ターン与えられる最大の期待ダメージ」を、**相手の現在 HP に対する割合**で返す（1.0 以上なら倒せる見込み）。`S.est(st, i, 技ID, target=)` も同じ単位。`S.faster(st, i)` は先に動けるとき 1.0、遅いとき 0.0、同速 0.5。
- `S.lookahead_action(st, i, depth)` はルートの全行動を評価して最大値の 1 手だけを返す。順位つきの一覧は返さない。

### 1.3 ブラインドテスト（refine.py）
- `refine.blind_select(t)`: 相手 6 体の種族だけを見て、`battle.select(opp6, ignore_stored=True)` で自分の選出順を決める（記事の型は使わない）。戻り値は `(最善の選出順, 上位3つ)`。
- `refine.blind_play(args)`: `args = (party, kid, my_order, opp_order, seed, my_depth, opp_depth[, know])`。両者とも相手の型を推測（`belief()`：使用率データと見えた技）して読む。**最大 30 ターン**。決着しなければ `S.evaluate(st) > 0` で判定（`refine.game` は 25 ターン）。
- 実測（2026-10-20、このコンテナ、1 コア）: STEALTHY KILLER 相手 1 戦で、自分 3 手読みは 7.3 秒（23 ターン）、**自分 5 手読みは 67.5 秒（11 ターン、約 6 秒/ターン）**。30 ターンまで続くと 1 戦 3 分前後。4 コア。
- 実測の対戦例（自分 5 手読み、エンペルト→ドヒドイデ→グレンアルマ vs メガグソクムシャ→カバルドン→アシレーヌ）: ドヒドイデがメガ後のグソクムシャ（むし・はがね）に**どくどくを撃って無効**になり、トーチカ・じこさいせいの間につるぎのまいを積まれて 3 タテされた。負け原因 (1) の実例。

### 1.4 現状の選出は規則を守らない（事実）
`blind_select` の R9 での結果（実測）:
- STEALTHY KILLER（アシレーヌ入り）→ セグレイブ・エンペルト・マスカーニャ。**ドヒドイデが入っていない**。
- 最終日にイエカメの奴（アシレーヌ入り）→ エンペルト・ドヒドイデ・マスカーニャ（規則は満たす）。

## 3. 選出規則

### 3.1 規則（ユーザー指示）
- **S1**: カバルドンとエンペルトは同時に選出しない。
- **S2**: カバルドンとエンペルトのどちらか 1 体は必ず選出する（目標: ステルスロックを必ず撒く）。
- **S3**: 相手の 6 体にアシレーヌがいるときは、ドヒドイデを必ず選出する（目標: 毒を撒く）。
  - ユーザー指示は「どくびし/どくどくを撒く」だが、R9 のドヒドイデの技は じこさいせい・どくどく・トーチカ・まとわりつく で、**どくびしは覚えていない**。本仕様では「どくどくを入れる」と読み替える（§4 の T1）。

R9 では 3 つは常に同時に満たせる（ドヒドイデ＋カバルドンかエンペルト＋残り 1 体）。

### 3.2 実装（battle.select に絞り込みを足す）
- `battle.select(opp6, seconds=10.0, ignore_stored=False, return_all=False, order_filter=None)` に引数 `order_filter`（`list[str] -> bool`）を追加する。`None` のときは今と完全に同じ動きにする。
- 処理: 60 通りの `orders` を作り、既存の `select_rules.json` の絞り込みを適用した**後**で、`kept = [o for o in orders if order_filter(o)]` とし、`kept` が空でなければ `orders = kept`。
- 保存済みの `counter`（記事に対する事前計算）を使う分岐は、`order_filter` が与えられていてその選出が規則を満たさないなら使わない（`blind_select` は `ignore_stored=True` なので通常は通らないが、念のため）。
- `refine.blind_select(t, order_filter=None)` も引数を受けて `B.select` にそのまま渡す。
- 規則の関数は `policy.py` に置く:
  ```python
  def select_filter(opp6, relax=()):
      ashi = 'アシレーヌ' in {battle._base(x) for x in opp6}
      def ok(order):
          s = set(order)
          rk = len(s & {'カバルドン', 'エンペルト'})
          if 'S1' not in relax and rk > 1: return False
          if 'S2' not in relax and rk < 1: return False
          if 'S3' not in relax and ashi and 'ドヒドイデ' not in s: return False
          return True
      return ok
  ```
- **満たせない場合のフォールバック**（パーティ変更で起こりうる）: 60 通りの中に条件を満たす選出が無ければ、S3 → S1 → S2 の順に 1 つずつ外して再判定する。外した規則は plan と結果に `relaxed: ['S3']` のように記録し、レポートに出す。R9 では起きないはず。
- 選出の中での先発と順序は、今の `select` の評価（貪欲な対戦＋上位 12 を 1 手読みで再評価）に任せる。

## 4. 行動規則（自分の行動の上書き）

### 4.1 しくみ
- 新規 `pokechamp/tool/policy.py` に置く。相手側（side 1）の行動と、探索の中身（読みの木の中の手）は変えない。**実際に打つ自分の 1 手（ルート）と、自分側の交代先（chooser）だけ**を変える。
- 規則は**相手の真の型を見ない**。使うのは `belief(st, 1, t_opp, seen[1])` で作った推測状態 `bst` と、見えている情報（種族、HP の割合、状態異常、能力変化、場の状態、ばけのかわ、メガかどうか、見えた技）だけ。自分側の合法手は `E.actions(st, 0)` で取る（自分の情報なので真の状態でよい）。
  - 例外: 交代先の chooser は `E.step` の中で真の状態を受け取る。既存の `S.chooser` も同じなので、chooser の規則は見えている情報（種族・HP・能力変化・ばけのかわ・メガ）と `S.switch_score` だけを使う。
- 探索の順位: `policy.ranked_root(bst, depth, k_self=3, k_opp=2)` を作る。`S.lookahead_action` のルートの処理を写し、`[(値, 行動), ...]` を値の大きい順で返す（`front_bias` も同じく加える）。**先頭の行動は `S.lookahead_action(bst, 0, depth)` と必ず一致させる**（受け入れ条件 A4）。規則ありの対戦では `lookahead_action` の代わりにこれを 1 回呼ぶので、計算量は増えない。
- 規則の形は 2 種類:
  - **指定**: 特定の行動に置き換える。
  - **禁止**: ある行動を候補から外し、順位表で禁止されていない最上位の行動にする。全部禁止されたら上書きしない。
- 規則は ID で個別に有効・無効を切り替えられる（`rules` 引数。既定は全部有効）。

### 4.2 共通の補助関数（policy.py）
- `base(m)`: `battle._base(m.name)`。
- `is_mega(m)`: `m.mega_form is not None and m.form is m.mega_form`。
- `find(acts, mid)`: `acts` の中から `a[0]=='m' and a[1]==mid` のタプル。無ければ `None`。
- `danger(bst)`: `S.best_damage(bst, 1)`。相手の場のポケモンが今ターン、自分の場のポケモンに与える最大期待ダメージ（自分の現在 HP に対する割合）。能力変化・天気・壁を含む。**危険が低い** ＝ `danger(bst) < RISK`（`RISK = 0.85`、定数）。
- `ko_now(bst, a)`: `a` が攻撃技で `S.est(bst, 0, a[1]) >= 1.0`、かつ（`S.faster(bst, 0) == 1.0` または技の優先度 > 0）。
- `can_poison(bst, f)`: 相手 `f` にどくどくが入るか。次のすべてを満たすとき True。
  - `f.alive`、`f.status == ''`、`'substitute' not in f.vol`。
  - `E.Battle(bst).types(f)` に `poison` も `steel` も無い。**メガ前でも、`f.can_mega` かつ相手側がまだメガしていない（`not bst.sides[1].mega_used`）なら、`f.mega_form.types` も見る**（グソクムシャはメガ前 むし・みず、メガ後 むし・はがね。メガはそのターンの技より先なので、どくどくは外れる）。
  - 特性（`E.Battle(bst).ab(f)`）が `immunity`・`purifyingsalt`・`comatose`・`goodasgold`・`magicbounce`・`pastelveil`・`poisonheal` ではない。`leafguard` は晴れでないとき可。
  - 相手側に `safeguard` が無い。`bst.terrain == 'mistyterrain'` で相手が接地しているときは不可。
- `rocks_useful(bst)`: 相手側に `stealthrock` が無く、相手の控えに生きている個体が 1 体以上いる。
- 1 試合の状態 `ctx`: 相手 6 体の base 名、`ashi`（アシレーヌ入りか）、有効な規則、ターン数、自分の前ターンの技、規則の発動記録 `fired=[(ターン, 規則ID, 元の行動, 新しい行動)]`。

### 4.3 規則一覧（発動条件・行動・解除条件）
自分の場のポケモンを `me`、相手の場のポケモンを `foe` と書く。ダメージの数字は calc.py（R9 の実数値、相手は該当構築の記事の型）で確認したもの。

**K（倒せるなら倒す。ガード）**
- 発動: 探索の 1 位 `a0` が `ko_now(bst, a0)`。
- 行動: 上書きしない（R1・T1・M1・Z2・D1・S9 より強い。G1・M2・X1 の禁止は `a0` が攻撃技なので当たらない）。
- 解除: 毎ターン判定し直す。

**R1（ステロを最優先で撒く）** ― ユーザー指示
- 発動: `base(me)` がカバルドンかエンペルト、`find(acts,'stealthrock')` がある、`rocks_useful(bst)`、`danger(bst) < RISK`、相手の場がマジックミラー（`magicbounce`）でない、M1・M2 が発動していない。
- 行動: `('m','stealthrock',…)`。
- 解除: 相手側にステロが置かれた（`cond['stealthrock']`）。こうそくスピン・きりばらい等で消えたら再び発動してよい（1 試合 2 回まで）。
- 根拠: 相手が受けに回る構築（C11）でもステロは控えに入る。メガリザードンY（ほのお・ひこう）にはステロだけで 50%。

**R1b（交代先でステロ要員を優先。chooser）**
- 発動: 自分が交代先を選ぶとき（倒れた後・クイックターン/とんぼがえりの後）、相手側にステロが無く、相手の控えが生きていて、候補にカバルドンかエンペルトがいて、その `S.switch_score` が候補中の最大値 − 0.15 以上。G1r・Z1 が発動していない。
- 行動: そのステロ要員を出す。
- 解除: 相手側にステロがある。

**T1（ドヒドイデはどくどくを最優先）** ― ユーザー指示・負け原因 (3)
- 発動: `base(me)=='ドヒドイデ'`、`find(acts,'toxic')` がある、`can_poison(bst, foe)`。アシレーヌ入りの相手では必ず有効。アシレーヌ無しの相手でも有効（負け原因 (3) の対策。`--rules` で T1 を外すと比較できる）。
- 行動: `('m','toxic',…)`。トーチカ・まとわりつく・じこさいせいより先。
- 解除: `foe` が毒状態（`psn`/`tox`）、または `can_poison` が偽（鋼・毒タイプ、メガ後に鋼になる、みがわり、他の状態異常など）。
- 注意: 毒が入らない相手（例: メガグソクムシャ、エアームド、ブリジュラス、ルカリオ、サーフゴー、ゲンガー、キラフロル）には撃たない。評価 20 構築の中で、6 体すべてがどくどく無効なのは 6abd49d9（鋼統一）。

**D1（回復の撃ちすぎを止める）** ― 負け原因 (3)
- 発動: `me` がドヒドイデかカバルドンで、探索の 1 位がじこさいせい・なまける、かつ `me.hp / me.maxhp > 0.6`。
- 行動: その回復技を禁止し、順位表の次の行動にする。
- 解除: HP が 60% 以下になった。
- 根拠: 回復は最大 50%。HP 60% 超で使うと回復量が余り、手番を失う。25〜30 ターンで決着せず判定負けになる原因 (3) を減らす。

**G1（積んだメガグソクムシャの前でドヒドイデが回復で粘らない）** ― 負け原因 (1)
- 発動: `base(foe)=='グソクムシャ'`、`foe.boosts['atk'] >= 2`、`base(me)=='ドヒドイデ'`。
- 行動: じこさいせいを禁止する（トーチカ・まとわりつく・交代は探索に任せる）。
- 解除: `foe` が場から離れた、または攻撃の能力変化が +1 以下になった。
- 根拠（calc）: メガグソクムシャ（STEALTHY KILLER の型、いじっぱり H23 A20）の +2 インファイト／アイアンヘッドはドヒドイデに 45〜53%。メガ後はむし・はがねで、どくどくは無効、まとわりつくは半減。ドヒドイデには削る手段が無く、回復を続けると +4 まで積まれて崩れる。ドヒドイデが倒れた後に、タスキが残ったグレンアルマを無償で出す（G1r）方が勝ち筋が残る。

**G1r（積んだグソクムシャの前に出すのはタスキのグレンアルマ。chooser）**
- 発動: 自分が交代先を選ぶとき、`base(foe)=='グソクムシャ'` で `foe.boosts['atk'] >= 1`、候補にグレンアルマがいて HP 満タン（タスキ有効）、持ち物が残っている。
- 行動: グレンアルマを出す。
- 解除: 条件を外れたら通常の chooser。
- 根拠（calc）: グレンアルマの素早さ 127 はメガグソクムシャ（60〜82）より速く、アーマーキャノンは 215〜257% で確 1。+2 ふいうちは 147〜174% だが、HP 満タンならタスキで残る。HP が減っていると +2 ふいうちで先に倒れるので、無償で出せるときだけにする。
- 不採用: 「グレンアルマが みちづれ でふいうちを読む」規則は、読み合いで正しさが決まらないので入れない。

**M1（ばけのかわが残ったミミッキュには、ステロ要員は先に皮を剥がす）** ― 負け原因 (2)
- 発動: `base(foe)=='ミミッキュ'`、`foe.ability=='disguise' and foe.busted is False`、`base(me)` がカバルドンかエンペルト。
- 行動: カバルドンは じしん。エンペルトは、生きている控えがいれば クイックターン、いなければ なみのり。その技が合法手に無ければ上書きしない。
- 解除: ばけのかわが剥がれた（`busted` が `False` でない）。剥がれた後は R1 に戻る。
- 根拠（calc。皮が無い場合の値）: じしん 45〜54%、なみのり 34〜40%。皮を残したまま つるぎのまい を通すと、+2 じゃれつくでカバルドン 62〜74%、エンペルト 41〜49%、かげうち +2 でグレンアルマ 93〜112%。皮を剥がしておけば、後続のドヒドイデ（+2 じゃれつく 38〜45%、どくどく可）で受けられる。
- 仮説扱い: ステロより先に攻撃するのが良いかは、R1 だけの場合と比べて確かめる（§5.4 の追加比較）。

**M2（積んだミミッキュには変化技を撃たない）** ― 負け原因 (2)
- 発動: `base(foe)=='ミミッキュ'` で `foe.boosts['atk'] >= 2`、`base(me)` がカバルドンかエンペルト。
- 行動: ステルスロック・あくび・なまける を禁止する（攻撃・交代は探索に任せる）。
- 解除: `foe` が場から離れた、または攻撃の能力変化が +1 以下。

**Z1（メガガブリアスZの前に出すのはスカーフのマスカーニャ。chooser）** ― 負け原因 (5)
- 発動: 自分が交代先を選ぶとき、`foe` の形が「メガガブリアスＺ」（`foe.form.ja`）、候補にマスカーニャがいる。G1r が発動していない。
- 行動: マスカーニャを出す。
- 根拠（calc）: マスカーニャの素早さはスカーフで 288、メガガブリアスZ（201〜203）より速い。トリプルアクセルは 113〜137% で確 1。逆にりゅうせいぐんはマスカーニャに 112〜133% なので、**相手の攻撃を受ける交代では出さない**（X1）。

**Z2（マスカーニャはガブリアスにトリプルアクセル）**
- 発動: `base(me)=='マスカーニャ'`、`base(foe)=='ガブリアス'`、`find(acts,'tripleaxel')` がある（こだわりで別の技に固定されていれば無い）。
- 行動: `('m','tripleaxel',…)`。
- 解除: 毎ターン判定。

**X1（相手の攻撃で倒される交代はしない）** ― 負け原因 (5) の補助
- 発動: 探索の 1 位が交代 `('s', j)` で、相手の場のポケモンの最大期待ダメージ（`S.best_damage` をその控え `j` に向けて計算。`target=bst.sides[0].mons[j]`）が、`j` の現在 HP 以上。ただし `j` がタスキで HP 満タンなら除外しない。
- 行動: その交代を禁止し、順位表の次の行動にする。
- 解除: 毎ターン判定。
- 根拠（calc）: メガガブリアスZ のりゅうせいぐんは マスカーニャ 112〜133%、メガセグレイブ 135〜160%。メガボーマンダ +1 すてみタックルは ドヒドイデ 96〜113%。メガライチュウY のでんじほう（ノーガード）は エンペルト 114〜135%、ドヒドイデ 96〜112%。

**S9（打点も役割も無い居座りをやめる）** ― 負け原因 (4)
- 発動: 次のすべて。`S.best_damage(bst, 0) < 0.10`（自分の技で 10% も削れない）。自分の変化技が役に立たない（ステロは相手側に既にある／`rocks_useful` が偽、どくどくは `can_poison` が偽、あくびは相手が状態異常か `yawn` 状態、回復は D1 で禁止）。控えに `S.best_damage(bst, 0, attacker_slot=j) >= 0.30` の個体がいて、X1 に当たらない。
- 行動: その中で `best_damage` が最大の控えに交代する。
- 解除: 毎ターン判定。
- 根拠（calc）: エアームドに対して、カバルドンのじしん・ドヒドイデのどくどく・ステロ（ステロはエアームド自身へは等倍 12.5%）が通らない。グレンアルマのアーマーキャノンは 169〜200%（メガエアームドにも 137〜164%）、エンペルトのなみのりは 44〜51%。

### 4.4 優先順位（矛盾したとき）
上から順に判定し、**最初に「指定」した規則で決める**。「禁止」は累積して、最後に禁止されていない最上位の行動を選ぶ。

1. 合法手が 1 つ以下、こだわり・あばれる等で固定、反動 → 上書きしない。
2. K（倒せるなら倒す）→ 上書きしない。
3. 禁止: X1、G1、M2、D1（ここまでの禁止を記録）
4. 指定: T1（ドヒドイデ）
5. 指定: M1（ステロ要員 vs 皮ありミミッキュ）
6. 指定: R1（ステロ）
7. 指定: Z2（マスカーニャ vs ガブリアス）
8. 指定: S9（居座りをやめる）
9. 指定が無ければ、禁止されていない最上位の行動（禁止が無ければ `a0` のまま）。

指定した行動が 3. の禁止に当たるときは、その指定は無効にして次の規則へ進む（例: M2 でステロが禁止されていれば R1 は発動しない）。

chooser の順位: G1r → Z1 → R1b → 既存の `S.chooser`。

### 4.5 blind_play への組み込み（refine.py）
- `refine.blind_play(args)` の `args` に 9 番目の要素 `rules`（`None` または規則 ID の tuple）を追加する。`None` のとき（既存の呼び出し）は**今とまったく同じ動き・同じ結果**にする。
- `rules` があるとき:
  - 自分の手は `bst = belief(st, 1, t_opp, seen[1])` を 1 回作り、`ranked = policy.ranked_root(bst, my_depth)`、`a0, rid = policy.choose(st, bst, ranked, ctx)`。
  - `E.step(st, a0, a1, rng=rng, chooser=policy.make_chooser(ctx))`。`make_chooser` は side 0 のときだけ §4.4 の chooser 規則を使い、side 1 は `S.chooser` を呼ぶ。
  - 発動した規則を `ctx.fired` に記録し、戻り値の dict に `fired`、`rocks_turn`（相手側に初めてステロが置かれたターン。無ければ `None`）、`tox`（ドヒドイデのどくどくで毒にした相手の base 名のリスト）、`turns`、`judged`（30 ターンで判定になったか）を加える。規則なしのときも `rocks_turn`・`tox`・`turns`・`judged` は記録する（比較のため）。
- 既存の `blind()`・`depth_study()` は変更しない。

## 5. 評価（core_test.py）

### 5.1 条件
- パーティ R9（§1.1 の手順）。自分 5 手読み（`my_depth=5`）、相手 3 手読み（`opp_depth=3`）、両者とも相手の型は推測（`know=False`）。最大 30 ターン。

- 乱数の種: `zlib.crc32(f'core{kid}{k}'.encode())`（k=0..4）。**on と off で同じ種**を使う。行動が分かれた後の乱数の並びは別になる（同じ種＝同じ出発点、という意味）。
- 条件ごとの選出:
  - `on`: `blind_select(t, order_filter=policy.select_filter(opp6))`、行動規則あり（全規則）。

  - 相手の選出は §2.4（両条件で同じ）。
- 選出と相手選出は最初に 1 回だけ計算して plan に保存し、再開時は再計算しない。
