# 【Reg M-C】スカーフイダイトウ＋ガブリアス＋メガメタグロス　上位構築対策のサイクル構築

## はじめに

ポケモンチャンピオンズ シングル Reg M-C 用の構築です。
上位構築（レート2000以上／1000位以内の記事）を多数読み込んだうえで、それらに対抗できる6体をシミュレーションで組み直しました。

- メガシンカ前提のポケモンは **メタグロス1体のみ**
- 苦手だった4構築（リザホーク、サザングロスアシレーヌ、重戦車、ジュペパモイダイ）に、明確に有利を取れる形を目標に調整
- 「カバルドンで機能停止しない」ことを重視（カバルドンが相手にいるとき、アシレーヌを必ず通す運用）

> 注意：数値の根拠は自作シミュレーターの結果（1構築あたり数戦〜十数戦）で、実戦での勝率ではありません。参考値としてお読みください。

## 構築の全体像

| No. | ポケモン | 持ち物 | 特性 | 役割 |
|---|---|---|---|---|
| 1 | イダイトウ | こだわりスカーフ | てきおうりょく | 上から殴るエース・メガグソクムシャ対策 |
| 2 | ガブリアス | きあいのタスキ | さめはだ | ステロ撒き・先制の削り |
| 3 | アシレーヌ | オボンのみ | げきりゅう | カバルドン・地面ポケへの回答／アンコール |
| 4 | ヒートロトム | たべのこし | ふゆう | 受けサイクルの軸・やけど撒き |
| 5 | ミミッキュ | いのちのたま | ばけのかわ | 剣舞エース・先制技で詰め |
| 6 | メガメタグロス | メタグロスナイト | かたいツメ | 先発・メガ枠（唯一） |

## コンセプト

1. **メガ枠は1体に絞り、残り5体で穴を作らない**
   メタグロスのみメガシンカ前提。他の5体はメガなしで完結するため、相手のメガ対策に選出を縛られません。
2. **スカーフイダイトウで「速い水」を確保**
   メガグソクムシャなど、こちらの攻めを受けてくる相手の上から、ウェーブタックル・れいとうビームで押し切ります。れいとうビームで、ガブリアス・ボーマンダ・カイリューなどのドラゴン、飛行にも打点を持てます。
3. **ガブリアスはタスキ型でステロを撒く**
   確実に1回動けるので、ステルスロックを置いてからメタグロス・ミミッキュ・イダイトウの圧力を通します。
4. **アシレーヌは、カバルドンへの回答を兼ねる**
   カバルドン（砂・あくび・ステロ）に他の5体は動きにくいため、相手にカバルドンがいるときは、アシレーヌを必ず選出に入れます。

## 個体解説

### イダイトウ（スカーフ）
- 性格：ようき
- 努力値：H2 / A32 / S32
- 技：ウェーブタックル／おはかまいり／クイックターン／れいとうビーム
- 解説：てきおうりょくで、水技・ゴーストの威力が上がります。クイックターンで、有利な相手への引き先を作り、れいとうビームで、ドラゴン・飛行・草・地面の受けを崩します。型は、15構築・約1,350戦のシミュレーションで6パターンを比較し、最も安定した型を選びました。アクアジェットを抜いてれいとうビームを採用した型が、最低勝率・平均勝率ともに最高でした。

### ガブリアス（タスキ）
- 性格：ようき
- 努力値：H2 / A32 / S32
- 技：じしん／げきりん／がんせきふうじ／ステルスロック
- 解説：タスキとさめはだで、先手を取りやすい相手には、ステロを置いてからの引き分けも狙えます。がんせきふうじで、相手の素早さを落として、味方のスカーフ・剣舞の通りを良くします。

### アシレーヌ（オボン）
- 性格：ひかえめ
- 努力値：H32 / B20 / C14
- 技：うたかたのアリア／ムーンフォース／アンコール／アクアジェット
- 解説：アンコールで、相手の積み技やステロ・あくびを止めます。カバルドンへ、うたかたのアリアで、打ち勝つことが主な役割です。アクアジェットは、削れた相手の先制の詰めに使います。

### ヒートロトム（たべのこし）
- 性格：ずぶとい
- 努力値：H32 / B32 / D2
- 技：オーバーヒート／ボルトチェンジ／おにび／いたみわけ
- 解説：ふゆうで地面技を透かしつつ、おにびで物理アタッカーの勢いを止めます。いたみわけとたべのこしで、サイクルの回復量を確保します。

### ミミッキュ（いのちのたま）
- 性格：いじっぱり
- 努力値：H1 / A32 / B1 / S32
- 技：じゃれつく／かげうち／つるぎのまい／シャドークロー
- 解説：ばけのかわで、1回の無償交代の機会を作り、剣舞から展開します。かげうちで、相手のスカーフ・タスキ持ちを倒す、詰めの役目です。

### メガメタグロス
- 性格：いじっぱり
- 努力値：H2 / A32 / S32
- 技：バレットパンチ／サイコファング／れいとうパンチ／じしん
- 解説：先発の第一候補です。メガシンカ後はかたいツメで、接触技の威力が上がります。バレットパンチ、サイコファング（壁破壊）、れいとうパンチ（ドラゴン対策）、じしん（炎・毒への打点）と、技の範囲が広く、先発で相手の構築を見極めながら削れます。

## 選出の考え方

シミュレーションで最善とされた選出を、まとめました。

### 基本選出

**メタグロス → ミミッキュ → イダイトウ**

- 相手のメガ枠・水・炎が多い構築に、先発メタグロスで削り、ミミッキュとイダイトウで締めます。
- 先発の候補は、メタグロス（最多）とミミッキュです。

### 裏選手・サイクル枠

- **ヒートロトム**：物理アタッカー中心の相手に、おにびとサイクルで対応します。
- **アシレーヌ**：カバルドン、地面を通したい相手、アンコールで止めたい相手に、選出します。
- **ガブリアス**：ステロが刺さる構築、足の遅い相手に、先発で出します。

### 相手に応じた選出

| 相手 | 選出 |
|---|---|
| カバルドンがいる | メタグロス → ガブリアス → アシレーヌ（アシレーヌ必須） |
| ジュペパモイダイ（154位） | イダイトウ → ガブリアス → ミミッキュ |
| 重戦車（142位） | ミミッキュ → アシレーヌ → イダイトウ |
| リザホーク（83位） | メタグロス → ミミッキュ → イダイトウ |
| グソクリザ（288位） | ミミッキュ → ヒートロトム → イダイトウ |

## 苦手な相手と立ち回り

- **リザホーク（83位）**：この構築で最も苦しい相手です。イダイトウの先手取りで、相手のスカーフ持ちを倒して、メタグロスで締めるルートを探します。選出ミスをしないことが重要です。
- **ジュペパモイダイ（154位）**：ガブリアスのステロとイダイトウのれいとうビームで、受け回しを崩します。
- **カバルドン入り構築**：先に決めたルールで、アシレーヌを必ず入れます。
- **水・ゴースト主体の並び**：ミミッキュのかげうち、イダイトウのスカーフ、アシレーヌのアンコールで、上を取ります。

## 検証について

- 上位構築の記事から取り込んだ、約14個のポケモンプールの中で、メガ枠1〜2体以内・ガブリアス必須の条件で、構築の組み合わせを探索しました。
- 第6枠は、メガニウムなどの候補も含めて、深さ3のシミュレーションで比較し、最も安定したイダイトウを採用しました。
- 結果は、サンプル数が少なく、1.00（全勝）などの極端な値は、偶然を含んでいる可能性があります。実戦の結果に応じて、調整していきます。
