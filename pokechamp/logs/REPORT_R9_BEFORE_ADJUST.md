# R9 並び対策レポート（調整前）

対象: `core_test.py` の4変種、計398戦（5手読み・ブラインド・相手は各構築の想定選出）。
変種: `on`（選出規則＋全行動規則）100戦／`on-NONE`（選出規則のみ）100戦／`on-no-M2+R1b`（R1b・M2を外した行動規則）100戦／`off`（規則なし）98戦。
**注意**: 1構築・1変種あたり5戦。同じ選出・同じ種の試合は変種をまたいで74%が同じ結果になる。表の「15/15」などは、実質は独立した5戦。誤差は±20%程度。

## 1. 規則の評価
| 変種 | 勝率 |
|---|---|
| off（規則なし） | 38% (37/98) |
| on-NONE（選出規則のみ） | 34% (34/100) |
| on（全規則） | 28% (28/100) |
| on-no-M2+R1b | 27% (27/100) |

- 行動規則は勝率を下げている。同じ選出・同じ種で `on` と `on-NONE` を比べると、`on`だけ負けた16戦・`on`だけ勝った10戦（差し引き-6戦）。R1b・M2を外しても改善しない（27%）ので、原因は別の規則（R1/T1/D1/X1/S9）の組み合わせ。
- 選出規則（カバルドン・エンペルトの片方だけ／アシレーヌ入りではドヒドイデ）の影響は-3pt程度で、誤差の範囲。
- ステルスロックを撒けた試合は撒けなかった試合と勝率が同じ（31% 対 32%）。2ターン以内に撒いても34% 対 28%で有意差なし。**ロックを撒くこと自体は勝因になっていない**。
- どくどくが入った試合は52%(47/91)、入らなかった試合は26%(79/307)。**毒を入れられるかが最大の勝因**（ただし、毒を入れやすい相手を選んでいる偏りあり）。

## 3. 最も負ける選出と行動
| 選出 | 結果 | 備考 |
|---|---|---|
| エンペルト→マスカーニャ→グレンアルマ | 0/15 | ガブエッテ軸。打点はあるが受けがない |
| セグレイブ→ドヒドイデ→エンペルト | 0/15 | 鋼・受け軸。ステロ・どくどくが通らず、打点不足 |

- エンペルトは選出された試合の勝率が23%で最低（他は33〜37%）。グレンアルマは負け試合で最初に倒れる個体が最も多い（85回）。

- 鋼・受け軸（エアームド等）には**38戦0勝**。選出・行動のどちらを変えても勝てていない。
