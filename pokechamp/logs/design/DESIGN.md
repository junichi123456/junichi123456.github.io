# 構築の見直し（design.py）

条件: メガシンカ前提は2体まで、ガブリアスを含める。候補14体（現6体＋カバルドン・リザードン・イダイトウ・ボーマンダ・ブリジュラス・セグレイブ・カイリュー・グソクムシャ）から6体、756通り。
対象は学習済みの上位構築20件（順位の高い順）。

## 手順
1. 全1,092選出（3体＋先発）を上位20構築の想定選出と1手読みで対戦（7.9万戦）。1手読みでは相手が弱すぎて、ほぼ全パーティが99%台に張り付いた（区別できない）。
2. 上位8パーティ＋現パーティの、各構築への上位6選出を3手読みで再対戦（1,518戦、新しい乱数）。

## 3手読みの結果（20構築への加重平均）
| 6体 | 点数 |
|---|---|
| ガブリアス・アシレーヌ・ヒートロトム・ミミッキュ・メタグロス＋ブリジュラス | 0.654 |
| 同＋グソクムシャ | 0.645 |
| 同＋リザードン | 0.641 |
| 同＋セグレイブ | 0.641 |
| 同＋イダイトウ | 0.639 |
| 同＋ボーマンダ | 0.617 |
| 現パーティ（ルカリオ入り） | 0.498 |
| ルカリオ・ガブ・アシレ・ロトム・メタグロス・カイリュー | 0.468 |

- 現パーティからルカリオを外した5体（ガブ・アシレ・ロトム・ミミッキュ・メタグロス）が核になると点数が上がる。
- 6枠目はどれを入れても0.64〜0.65で差が小さく、実戦でほとんど選ばれない（選出回数はブリジュラス1回、グソクムシャ0回）。6枠目は未確定。
- 苦手な構築: 83位リザホーク（0.25）、142位ムシャヌメルドン重戦車（0.19〜0.36）、154位ジュペパモイダ（0.46）、122位サザングロスアシレーヌ。
- 注意: 乱数のばらつきがあり（1パーティ約480戦）、点数差0.15は有意に近いが確定ではない。
