## 2. 最終構築

コンセプト: **「1対1で殴り勝てる高火力6体＋マルチスケイルのメガカイリュー」**。どの3体を選んでも、各個体が相手の1体と正面から打ち合って勝てる（＝相手の行動に依存しない）ことを最優先にした。積み技や天候・設置に依存しない（崩されにくい・再現性が高い）。メガ枠はメガカイリューの1体だけで、メガ無しの3体組も成立する。

## 3. 各個体の役割と動かし方

| 個体 | 役割 | 動かし方 |
|---|---|---|
| メガカイリュー | エース兼受け出し。マルチスケイルでほぼ全攻撃を一度は耐え、C216の4色打点で返す | 1ターン目にメガシンカ。HPが満タンでないとマルチスケイルが消えるので、削られたら「はねやすめ」で戻すか引く。ガブリアス/ボーマンダは「りゅうせいぐん」確定1発（163-192%、168-200%）。セグレイブの「つららおとし」は90-108%（乱数1発 9/16）なので対面させない |

## 4. 要件ごとの検証結果（数値）

評価方法（スクラッチ: `/tmp/w/m7hand.py` ほか）
- 相手: 使用率上位50種（M-6）。各種族の上位スプレッド2種×持ち物2種＝最大4型（メガストーン持ちはメガ形）。技は採用率15%以上のもの。
- 1対1判定: こちらの技の最低乱数で倒すまでの手数と、相手の技の最高乱数でこちらが倒れるまでの手数を比べ、素早さ（スカーフ込み）・先制技・きあいのタスキ・オボンのみ・マルチスケイル・ばけのかわ・いのちのたまの反動を反映。命中率と「りゅうせいぐん」「オーバーヒート」の能力低下（×0.85）も補正。
- 3体組の評価値 = 勝てる相手の割合（使用率で重み付け）＋0.5×2番手以降の厚み −0.06×壁を50%削れない数 −0.5×50%出せない相手の重み −0.25×一貫する攻撃タイプの重み。構築の評価 = 0.6×20通りの最低値 ＋ 0.4×平均。

## 6. 弱点と代案

### 弱点
- **鋼＋ゴーストの並び（メタグロス・ギルガルド）**: 「スターミー/フラエッテ/ブリジュラス」の組だけ3体とも負ける。この3体で出すときはヒートロトムかエンブオーを優先して入れ替える（この組は評価値も20通りで最低）。
- **ゴースト技の一貫**: スターミー・フラエッテ・エンブオーがゴーストを半減できず、ドラパルト／ミミッキュ／ギルガルドのゴースト技が通りやすい。ミミッキュは「メガカイリュー/スターミー/フラエッテ」で3体とも負け（ばけのかわ＋じゃれつく 45-54%）。
- **地面の重なり**: ブリジュラスとエンブオーはどちらも地面が弱点。ガブリアス・カバルドン・ラグラージの前で2体を同時に出さない。
- **反動・能力低下**: はめつのひかり・フレアドライブ・もろはのずつき（エンブオーは「いしあたま」ではない）・いのちのたまで自分のHPも減る。長期戦は不利（仮説: 受けループには時間切れ前に押し切れない場合がある）。
- **ヒートロトムのおにびを外した**: あくのはどうの方が評価値が高い（最低値 1.165→1.170）が、物理の積みアタッカー（セグレイブのりゅうのまい等）への保険は減る。気になるならおにびに戻す（評価値 −0.005）。

## 7. 採用しなかった候補とその理由

| 候補 | 理由（数値はこの評価での単体の1対1勝率＝使用率重み付け） |
|---|---|
| イルカマン（マイティ） | 単体の評価は最高（0.83）だが、一度交代しないとマイティにならない。交代の手間（場に出す→クイックターン→再登場）を勝率計算に入れられないので外した（仮説: 実戦ではこの手間で評価が大きく下がる） |
| ドリュウズ・バイバニラ・ドドゲザン（一撃技） | 一撃技（命中30%）を100%扱いすると上位に来るが、再現性の要件に反するので一撃技を除外した |
| マフィティフ | 特性「はりこみ」は交代で出てきた相手にだけ2倍だが、エンジンの計算では常に2倍になるため、正しく評価できないので除外 |
| メガスターミー（ちからもち） | 物理技がアクアブレイク・アイススピナー程度で、鋼・ドラゴンに通らない（単体 0.53）。メガ枠の他の候補とも衝突 |
| メガフラエッテ | 単体は 0.55〜0.58 だが、メガ形の learnsets に「はめつのひかり」が無い（ムーンフォースのみ）。非メガのフラエッテ＋メガカイリューの方が上 |
| メガゲンガー（かげふみ） | 閉じ込めは強いが、この評価では HP・耐久の低さで1対1の負けが多い（単体 0.40、構築 1.027） |
| カイリュー（非メガ・いのちのたま） | 単体 0.70 と高いが、メガカイリューと同じ種族なので同時に採用できない |
| エースバーン・マスカーニャ・ハッサム | タスキやスカーフでも鋼・壁への打点が不足（単体 0.23〜0.55） |
| ヒスイウインディ | 単体 0.68 と高いが、エンブオー・ヒートロトムと炎が重なり、カバルドン・ラグラージに弱い。入れ替えると最低値 1.051 |
| ミミッキュ | 旧案の弱点（5体の壁に打点不足）がそのまま残る（壁失敗1件、最低 1.099） |

## 8. M-6 データ前提の限界

- 使用率・型（持ち物・性格・能力P・技）はすべてシーズンM-6（2026-10-05）。M-7 の流行の変化（たとえばメガカイリュー対策の増加）は入っていない。`regulation.json` の `latest_season` が 8 になっており、M-C の記事はシーズン8表記でも出始めている。
- 相手の型は上位スプレッド2種×持ち物2種、技は採用率15%以上に限定。技の組み合わせは「4つ」ではなく採用率15%以上の全部を同時に持つとみなした（相手を強めに見積もる）。
- 1対1判定は、積み技・状態異常・ステルスロック・交代読み・急所・追加効果・ターン経過の回復（たべのこし等）を扱わない。メガカイリューのマルチスケイルの回復（はねやすめ）や、ブリジュラスのじきゅうりょくによる防御上昇の累積も評価値には入れていない（実戦ではこちらに有利な仮説）。
- 一貫の判定はタイプ相性のみ（相手のメインタイプ。サブウェポンは見ていない）。
- 再現性の評価は「選出と相手に依存せず1対1で勝てる割合」で代用した。実戦の勝率は `battle.py`／`prep.py` の対戦で別途確かめる必要がある（今回は回していない）。
- 計算スクリプト: `/tmp/w/m7lib.py`（エンジンでのダメージ計算）、`m7cand.py`・`m7team.py`・`m7search2.py`（全種族の自動生成と探索）、`m7sets.py`・`m7hand.py`・`m7hs2.py`・`m7hs3.py`（手作りの55型＋持ち物違い187型の評価と探索）、`m7final.py`・`m7rep.py`・`m7swap.py`・`m7calcs.py`（最終構築の検証）。
