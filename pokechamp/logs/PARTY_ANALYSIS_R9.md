# 新構築 分析（カバルドン／メガセグレイブ／ドヒドイデ／エンペルト／マスカーニャ／グレンアルマ）

方法: engine.py で3手読み同士の対戦。(A) 公開上位6構築×自分の60通りの選出順×相手の想定選出＝3,420戦（1組1戦）、(B) 使用率上位30種との1対1（各2戦）。
**サンプルが小さい**ので、勝率は目安（±10〜15%）。25ターンで決着しない対戦は残HPの評価で判定（ドヒドイデの回復合戦で多発）。

## 結論
- 全体勝率: メガリザXスタン3 56% / STEALTHY KILLER 47% / 水統一 57% / 積みヒトムアシレグロス 61% / 純正バンギムドー 51% / リザホーク 52%。**互角〜やや有利。強く勝ち越せる構築ではない。**
- 6構築平均で最も勝率が高い並び: **マスカーニャ→ドヒドイデ→グレンアルマ 73.6%**、次点 エンペルト→セグレイブ→ドヒドイデ 72.3%、セグレイブ→ドヒドイデ→エンペルト 68.6%。
- 最も低い並び: カバルドン→エンペルト→グレンアルマ 15%（受け2体＋打点不足で崩される）。**ドヒドイデを入れない並びは弱い**（ドヒドイデを出した時の平均勝率 58〜76%）。
- 最大の穴: **エアームド（受け構築）に全員が14〜28%**（グレンアルマだけ50%）。**メガグソクムシャ**（つるぎのまい→インファイト/アイアンヘッド）も共通の負け筋。

## 個体ごとの運用
### ドヒドイデ（最重要・ほぼ常に選出）
- 必ず出す: ハッサム(86%)・サザンドラ・バンギラス・ミミッキュ・アシレーヌ・ガブリアス・ペリッパー。
- 出せない: セグレイブ・カバルドン・ブリジュラス・サーフゴー・ゴリランダー・ボーマンダ・カイリュー・ウォッシュロトム（どくどく・まとわりつくで削りきれず、物理の高火力に押される）。ガラルヤドキング・メガグソクムシャ相手も不利（45〜55%）。
- 動き: 先発〜中盤に出し、まとわりつく→どくどく→トーチカで削りつつじこさいせいで耐える。タスキ・メガの積みわざには出さない。**回復合戦で決着しない対戦が多い**ので、どくどくを入れて早めにHPを削ること。

### カバルドン
- 必ず出す: 水統一以外の「ステロを撒けて相手の物理が多い構築」。ガブリアス、ルカリオ、メタグロス、ギルガルド、ラグラージ、オオニューラ、エースバーン、パーモット（1対1で勝ち）。
- 出せない: エアームド(14%)・メガグソクムシャ(44%)・メガニウム(43%)・水/草/氷の相手（ボーマンダ、アシレーヌ、ゴリランダー、サーフゴー、イダイトウ、ウォッシュロトム、ゲッコウガ）。
- 動き: 先発でステルスロック→あくび。じしん主体。水統一・草タイプ相手には出さない。リザホークには先発で有効（64%）。

### メガセグレイブ
- 必ず出す: ガラルヤドキング(95%)・バンギラス(87%)・メガニウム(71%)・ウォッシュロトム(75%)・ヒートロトム・ガブリアス・ボーマンダ・カイリュー・ゴリランダー・ラグラージ。
- 出せない: アシレーヌ（フェアリー）、サーフゴー、ブリジュラス、グソクムシャ、ルカリオ、アーマーガア、エアームド(23%)。
- 動き: メガシンカしてつららおとし主体、苦手に対してはこおりのつぶて（先制）。ドラゴン・地面・草・飛行の相手の「抜き役」。

### エンペルト
- 必ず出す: 相手が地面・炎・鋼の受け回し（カバルドン、ウルガモス、アローラキュウコン）、ミミッキュ、マスカーニャ、イエッサン。ステロ・あくびを撒く先発として、純正バンギムドーや水統一以外に。
- 出せない: 1対1で19種に負け（ガブリアス、ボーマンダ、アシレーヌ、ルカリオ、ゴリランダー、リザードン、エースバーン、イダイトウ、メタグロス、カイリュー、ウォッシュロトムなど）。**アタッカー受けにならず、単体では最も弱い**。
- 動き: 先発 あくび→ステロ→クイックターンで後続へ。居座らない。

### マスカーニャ（こだわりスカーフ）
- 必ず出す: ガブリアス、ボーマンダ、ゴリランダー、ゲッコウガ、ウォッシュロトム、ラグラージ、イダイトウ、カイリュー、カバルドン（水統一にも勝てる66%）。ミミッキュ入りにはトリプルアクセルで。
- 出せない: セグレイブ、ルカリオ、グソクムシャ、リザードン、エースバーン、ギャラドス、サーフゴー、ブリジュラス、エアームド（24%）。
- 動き: 先発でトリックフラワー（急所確定）かとんぼがえりで後ろに繋ぐ。素早さ192(スカーフ)で上から。イカサマは物理受けの相手に。

### グレンアルマ（きあいのタスキ）
- 必ず出す: エアームド（唯一50%）、サーフゴー、ブリジュラス、アーマーガア、ゴリランダー、キラフロル、オオニューラ、メタグロス、ギルガルド、エースバーン。
- 出せない: アシレーヌ、ガブリアス、ボーマンダ、ミミッキュ、リザードン、ウォッシュロトム、カイリュー、ラグラージ、ウルガモス。
- 動き: タスキで1回耐えてワイドフォース/アーマーキャノン。みちづれは相手が先に動いて倒してきたときの最後の押し込み。

## 有利な並びでも負ける原因
1. **メガグソクムシャの積み**: エンペルト/マスカーニャが先に倒され、ドヒドイデにつるぎのまい後のインファイト/アイアンヘッドが通り、残りも順に倒される。（上位2並びの負けの大半）
2. **ミミッキュのばけのかわ＋つるぎのまい**: 先発のあくびやステロの間に積まれ、後続の物理受けが足りなくなる。
3. **回復合戦で25ターン内に決着しない**: ドヒドイデのじこさいせい/トーチカの連打で、判定負け（評価で劣勢）になる。どくどくを早めに入れたい。
4. **エアームド・ブリジュラス等の鋼**: ステロ・どくどくが通らず、こちらの打点（セグレイブ以外）が足りない。
5. **ガブリアスZのメガ**: りゅうせいぐん/かえんほうしゃで、カバルドン・ドヒドイデ・エンペルトの受けが崩れる。マスカーニャ・グレンアルマのタスキ処理が必要。

## 調整の提案（種族・持ち物は変更なし／**未検証**）
今回のシミュレーションでは技・能力の変更は試していません。次の候補は仮説で、反映前に `refine.py --screen` で確認が必要です。
- エンペルト: 1対1で19種に負けるため、クイックターンかあくびをれいとうビームに替える案（ガブリアス・ボーマンダ・カイリュー・ゴリランダー対策）。
- グレンアルマ: はどうだんはほぼ使われないため、他の技への入れ替え案。
- マスカーニャ: イカサマの使用が少なく、入れ替えの余地あり。
