# 苦手な相手への選出早見表（R3パーティ）

対象は、ブラインドテストで最悪選出に負け越した構築、または型推定を強化した後に選出がずれて落とした構築です。
各相手の最悪選出に対して、こちらの全60選出を各6戦試しました（型既知・両者3手読み）。
そのうえで上位の選出を、ブラインド条件（型は推測、こちら4手・相手3手、各6戦）でも確かめています。
相手の6体が完全に一致したときは、`battle.py select` がこの選出を返します（known_teams.json の counter を上書き済み）。

## 早見表

| 相手の6体（記事） | 相手の最悪選出 | 出す選出（先発→） | 型既知 | ブラインド | 全選出の平均 |
|---|---|---|---|---|---|
| 炎氷乱舞（イエッサン・リザードンX・セグレイブ・アーマーガア・ニンフィア・イダイトウ） | ニンフィア → リザードン → アーマーガア | **ルカリオ → アシレーヌ → ヒートロトム** | 6/6 | 6/6 | 54% |
| 全壊ロンゲマンダ（メガフラエッテ・メガボーマンダ・ガブリアス・サーフゴー・オーロンゲ・メタモン） | サーフゴー → フラエッテ → ガブリアス | **ルカリオ → ガブリアス → アシレーヌ** | 6/6 | 6/6 | 60% |
| 爆速クエル（クエスパトラ・カイリュー・ラグラージ・ルカリオ ほか） | ラグラージ → ルカリオ → カイリュー | **アシレーヌ → ガブリアス → メタグロス** | 6/6 | 4/6 | 88% |
| リザホーク（リザードン・ミミッキュ・アシレーヌ・ムクホーク ほか） | ミミッキュ → リザードン → アシレーヌ | **ガブリアス → ルカリオ → アシレーヌ** | 6/6 | 5/6 | 50% |

- 「型既知」は相手の型を知っている場合、「ブラインド」は種族しか分からない実戦に近い条件での勝ち数です。
- 「全選出の平均」は、相手がほかの選出をしてきた場合も含めた平均勝率です（R3の結果）。

## 勝ち筋（シミュレーションで勝った試合の流れ）

### 炎氷乱舞：ルカリオ → アシレーヌ → ヒートロトム
- 先発のニンフィアには、ヒートロトムに引いてボルトチェンジで様子を見ます。
- メガルカリオZのラスターカノンでニンフィアを削り、リザードンが出てきたらアシレーヌに引きます。
- 倒す順はニンフィア → リザードン → アーマーガアです。
- アーマーガアのてっぺきとボディプレスには、特殊技（ルカリオ・アシレーヌ）で殴ります。物理アタッカーは出しません。
- 次点はガブリアス → ルカリオ → アシレーヌ（ブラインド5/6）です。ガブリアスがステルスロックとがんせきふうじで起点を作り、アシレーヌのアリアで締めます。

### 全壊ロンゲマンダ：ルカリオ → ガブリアス → アシレーヌ
- 先発はメガルカリオZです。1ターン目にわるだくみを積みます（相手のサーフゴーのシャドーボールやゴールドラッシュは耐えます）。
- あくのはどうでサーフゴーを、ラスターカノンでメガフラエッテを倒します。
- ガブリアスにははどうだんで削ってから倒します。3体ともルカリオで流せることが多いです。
- 3体目はミミッキュかメタグロスでもブラインド6/6でした。ヒートロトムは0/6なので出しません。

### 爆速クエル：アシレーヌ → ガブリアス → メタグロス
- アシレーヌのムーンフォースで削ります。ラグラージのあくびが来たら、ガブリアスに引いてげきりんを押します。
- 倒す順はカイリュー → ルカリオ → ラグラージです。
- あくびのループには、アシレーヌのアンコールが効きます。

### リザホーク：ガブリアス → ルカリオ → アシレーヌ
- ガブリアスのがんせきふうじでミミッキュの化けの皮をはがします（素早さも下げます）。
- 相手のかげうちとじゃれつくは、アシレーヌに引いて受けます。
- ムーンフォースでミミッキュを倒し、リザードンは残りのメンバーで倒します。

## 一般化できる教訓（6体が一致しない相手にも）

- **フェアリーと鋼が多い相手**（ニンフィア・メガフラエッテ・サーフゴー・アーマーガアなど）には、**メガルカリオZを先発**にします。
  - ラスターカノン（フェアリーに抜群）、あくのはどう（サーフゴー）、はどうだん（鋼）で全員に打点があります。
  - わるだくみを1回積めば流れを作れます。
  - この並びにヒートロトムやメタグロスで受けに回ると、ブラインドではほぼ勝てませんでした。
- **ミミッキュとメガリザードンの並び**には、**ガブリアスのがんせきふうじから入り、アシレーヌで受けて返す**のが安定します。
- **あくびや耐久で回す相手**（カバルドン・ラグラージ）には、**アシレーヌとガブリアス**を出し、アンコールで縛ってげきりんで崩します。
- 推定が外れやすい相手（記事にない型）では、選出の段階で「全員に打点がある3体」を優先します。
