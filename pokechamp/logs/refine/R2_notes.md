| アシレーヌ: オボンのみ→しんぴのしずく | 492 → 473 |
| ヒートロトム: たべのこし→ゴツゴツメット | 494 → 464 |
| ガブリアス: ようき→いじっぱり | 490 → 480 |
| ミミッキュ: いじっぱり→ようき | 490 → 488 |
| ヒートロトム: H32 B16 D18 | 494 → 483 |
