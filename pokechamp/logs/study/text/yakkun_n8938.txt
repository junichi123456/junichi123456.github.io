スポンサーリンク

使用ポケモン
ワルビアル@オボンのみ(しんちょう)いかく
HP:32 / 防御:10 / 特防:23 / 素早:1
(252表示: HP:252 / 防御:76 / 特防:180 / 素早:4)
実数値:202-137-110-76-124-113
じしんはたきおとすほえるステルスロック

初手ステロ要因
メガフラエッテが初手に出てきそうな相手以外には9割選出していた。(セグレイブ相手はステロした後カビゴンに交代)
C212メガライチュウＹのねこだまし+きあいだまを97.7%耐え。
アシレーヌのC195ムンホ確定耐え残りをBに振ってある。初手アシレーヌが多かったためこの調整にしている。(カイリューの枠がリザードンだったときは少なかったため、マスカーニャのトリックフラワー確定耐え残りをDに振っていた)

技採用意図
じしん…一番火力が出る
はたきおとす…こだわりスカーフやオボンのみ食べ残し
等のルカリオの全抜きを邪魔する相手に打つ　　　　　　　　　　　　　　　　　
ほえる…起点回避が目的。ピクシーバトン相手だとステロ打った後、適当なタイミングでほえるして出てきたメガピクシーの瞑想に合わせてほえるを押すとマジックミラーで反射するため相手の技を見てからルカリオに交換できる。環境次第でドラテに変えるのもあり。
ステルスロック…必須技

カビゴン@たべのこし(わんぱく)あついしぼう
HP:22 / 防御:32 / 特防:12
(252表示: HP:172 / 防御:252 / 特防:92)
実数値:257-130-128-76-142-50
あくびれいとうパンチじしんまもる

あくび要因カイリューを選出しない場合は100%選出する。初手が起点作成した後に交代で出す事が多い。
A200オオニューラインファイトを確定耐え残りをD振り。
技採用意図
あくび…ステロorまきびし+あくびで相手をルカリオの技圏内にもちこむまたは、悪巧みのチャンスを作るため必須。
れいとうパンチ…ガブリアスやボーマンダへの打点。環境調整枠。
じしん…非接触でゴーストへの打点になり追加効果がないためあくびを阻害しない。環境調整枠。
まもる…サトシパで食べ残しあくびするなら必須。体力管理や相手を眠らせたいときに使う。技採用率が10位より下だったため、チャンピオン級でもまもるをケアせず眠気状態のまま居座り眠らせることが多々あった。

メガルカリオZ@ルカリオナイトZ(おくびょう)はどうのぼうご
防御:2 / 特攻:32 / 素早:32
(252表示: 防御:12 / 特攻:252 / 素早:252)
実数値:145-108-92-216-90-223
はどうだんあくのはどうてっていこうせんわるだくみ

エース枠。ステロ+あくび等で準備ができた後に出す。
メガZ達が解禁されたとき、最速振りは少なく同速対決は少ないと予想していたため最速振りにした。20回近くメガZ対面したが1度だけしか同速負けしなかった。
サトシパに強い壁要因はいないため耐久振りは選択肢になかった。

技採用意図
はどうだん…てっていこうせんを打ちたくない場面での打点。
あくのはどう…サーフゴーギルガルドメタグロス等への打点。シャドーボールは流行っていたイエッサンに無効化され、耐久振りしてないためdダウンの恩恵が少ないこと、火力が届かないとき怯みで勝ちを狙えるのが強い。60近く打って5回怯ませた。
てっていこうせん…ラスターカノンだと悪巧みしてもアシレーヌを落とせないため確定。ステロを絡めて悪巧みすると、タイプいまひとつのオボンのみウルガモスも68.8%で落とせる。

ゲッコウガ@きあいのタスキ(ひかえめ)へんげんじざい
HP:2 / 特攻:32 / 素早:32
(252表示: HP:12 / 特攻:252 / 素早:252)
実数値:149-103-87-170-91-174
れいとうビームヘドロウェーブくろいきりまきびし

初手まきびし要因
メガフラエッテ等のワルビアルがどうしても出せないときに選出する。
ボーマンダが少なく最速振りが極めて少ないこと、パーモットより遅いがねこだましやマッハパンチがきついため火力重視のひかえめにした。

技採用意図
れいとうビーム…ガブリアスやボーマンダ、カイリュー等への打点。
ヘドロウェーブ…アシレーヌフラエッテ等への打点。
くろいきり…自由枠。瞑想や剣の舞への対策。
まきびし…ワルビアルの代わりに選出するため必須。どくびしだとあくびを阻害する。

カイリュー@ゴツゴツメット(いじっぱり)マルチスケイル
HP:31 / 攻撃:26 / 素早:9
(252表示: HP:244 / 攻撃:204 / 素早:68)
実数値:197-198-115-108-120-109
しんそくドラゴンテールじしんはねやすめ

エースバーンやグソクムシャメタモンへの対策枠。相手をルカリオ圏内に押し込む役割。調整意図はYouTubeのパクリなため覚えていない。
最終日前日まではHBC振りリザードンＹを使っていたがYouTubeをきっかけに耐久振りが周知されたためか、岩技が増えてきつかったため、エースバーンへ強くスカーフガブリアスの一貫を切れるゴツメカイリューを採用した。

技採用意図
しんそく…確定枠。足りない削りを補う。
ドラゴンテール…設置技と合わせると強い。ルカリオ圏内に押し込むのが役割なため確定。
じしん…非接触の高打点。
はねやすめ…これがないと受けもサイクル戦もできないため確定。

ピカチュウ@(持ち物なし)(ずぶとい)せいでんき
HP:32 / 防御:32 / 素早:2
(252表示: HP:252 / 防御:252 / 素早:12)
実数値:142-67-101-70-70-112
ほっぺすりすりアンコールフェイントがむしゃら

選出率0%。元々タスキやゴツメを持たせていたが他と競合したため持たせる物がなかった。最終日に血迷って選出しないように持ち物はなしにした。

現環境のピカチュウのキツさ
電気球
昔と違いS156より速いポケモンが増え先制技が増えた。めざめるパワーがないため、例えアシレーヌ等の刺さる相手が来ても交代された後有効打が少なく選出しても活躍できるチャンスが極めて少ない。ガブリアスが重すぎる。

きあいのタスキ
耐久と火力が低すぎるため初手にしか出せずがむしゃらフェイントは相手が都合よく攻撃するタイミングを合わせないといけない。相手より速い場合体力満タンなため強い技選択(ステロやまきびし等)ができない。ガブリアス相手だと、スケショは耐えずステロされるとがむしゃらで鮫肌に触れてじしんでやられる。

ピカチュウの使い勝手
現状アタッカーかタスキくらいしか使い方がなく、役割を果たせず実質2VS3になるリスクが高すぎて選出できない。
ダイマ環境が来たときには進化の輝石もあると思うため、そのときにはダイジェットに受け出しして守る願い事でサイクルしたりアンコールで起点回避する等の役割が生まれる。そのときがピカチュウが活躍する唯一無二のチャンスかもしれない。

戦術と解説

チームID　EQ5KKF2UJM

基本選出
ワルビアルorゲッコウガ+カビゴン+ルカリオ
てっていこうせんは自爆技なためルカリオ以外の体力を残す意識が大事。

この構築はルカリオZが活躍するかどうかに勝敗がかかっているため、カビゴンからどのタイミングで交代するかで勝敗が決まる交代にプレイングが出る。
ミミロップが重すぎるため、初手ルカリオから出して交代読み技選択することがあった。
構築弄るならゲッコウガとカイリューの枠。
