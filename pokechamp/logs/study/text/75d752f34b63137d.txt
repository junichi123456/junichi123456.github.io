結果
構築経緯
環境に多い構築の要点を洗い出し、それぞれにメタを貼る方向で考え始めた。
パモイダイ対面構築スイーパーとして多いイダイトウ、ドドゲザンに対して、ゴリランダーの火力UPアイテムグラススライダー+馬鹿力でそれぞれ上から縛ることが可能なので採用した。パーモットの気合の襷をステルスロックで回避しながら上から縛ることを考えていたが、メガピクシーがステルスロックを拒否してくるため、「メガピクシーに対面勝つ→パーモットを大きく削る」ができるポケモンとして鉄蹄光線メガルカリオZを採用した。パーモットには気合の襷を盾に行動を許してしまうが、・インファイト、電光送撃であれば倒されながらもゴリランダーで縛れる。・再起の祈りであれば波動弾+真空波で対面突破してもう一度メガピクシーに鉄蹄光線。・ほっぺすりすりであれば真空波で対面突破可能。イダイトウにはゴリランダーのグラススライダーがあるので問題なし。ドドゲザンは1回は技を耐えるので真空波でグラスラ圏内へ。よってこの手の構築に対してはメガルカリオZ+ゴリランダー+@1で選出が安定していると考えた。

ゴリランダー、マスカーニャ、ミミッキュがいる構築メガルカリオZの採用を考えたとき、サイコフィールド+メガカメックスの通りが非常によく、上記3匹がストッパーとして優秀であるという共通認識がある。イエッサン+メガカメックスが非常に選出誘導能力が高く、そのうえで明確なストッパーがいない構築に対してはイージーウィン性能が高いという点に目を付けた。これらの対策ポケモンは総じてメガルカリオZに弱く、選出を誘導しながら有利なサイクルを展開していけると考えた。他に止める手段として気合の襷、頑丈が挙げられるが、これをステルスロックによって拒否できると考えた。ステルスロックを撒くポケモンとしてカバルドン、ガブリアス、ブリジュラスが候補に挙げられる。その中で対フラエッテ、リザードン性能が最も高い気合の襷最速ガブリアスを使うことにした。基本的にメガルカリオ+@2の選出が成立していると考えた。

ドヒドイデ+悪タイプ入り構築メガルカリオZがフルアタ構成なため、本来はドヒドイデ入りに勝てるはずが勝てないという事件が起こっている。普通に考えたらイエッサンいたらドヒドイデは余裕ではあるのだが、ヒスイダイケンキなどの悪タイプいたら余裕でしんどいため、別で対策枠を考える必要があると考えた。思考の果てにサイコノイズアシレーヌが、・悪タイプへの対策枠となり、かつドヒドイデの選出が誘導できる。・ムーンフォース、瞑想と併せて採用することで高い汎用性と両立できる。・マスカーニャに対してはメガルカリオZが強く、ゴリランダーのグラスフィールドと併せて竜地面耐性を獲得できるなど前述した並びと相性が良い。・グソクムシャの吸血をサイコノイズによって封じることができるため、グソクムシャを大きく削る性能が高い。など選出の可能性を大きく広げることができると考えて採用した。

ここまでで、構築に欲しかった要素を満たすことができたと考えたので、構築を完成とした。

個体紹介
ゴリランダー　NN パワー！！！

調整意図
A : 受けきることを許したくないためガチ特化
S : S1段階下降した最速110族抜き + S実数値115あたりのチキンレースラインを余裕をもって抜く
H : あまり
本構築の軸となるストッパー圏スイーパー。フィールドの魔術師その1。
構築経緯で書いた通り、イダイトウ+ドドゲザンに対して無類の強さを誇るポケモンと感じていたので採用した。持ち物の候補としてラムや奇跡の種があるが、ラムは素の火力が足りずにB振りイダイトウに耐えられる可能性があること、命の珠+剣舞グラススライダーでH2振りガブリアスを13/16で落とせること、馬鹿力に火力補正をかけることでアーマーガアに勝てる可能性があることから命の珠で採用した。
カバルドンに対してかなり圧力があり有利なポケモンという認識。ドラムアタックはカバルドンを一撃で倒せるウッドハンマーと選択だが、S下降という優秀な起点回避要素があるため、今回はドラムアタックを選択。
後述するイエッサン+カメックスが電気に弱いという
草格闘という貧弱な技範囲ではボーマンダやカイリューに隙を見せてしまうと思われたが、S下降ギミック要素のおかげで最低限しか仕事をさせずに対応できてよかった。
ゴリランダーのおかげでイージーウィンを多く拾うことができたと考えている。

ルカリオ　NN ライバ　ロリ

調整意図
C : 臆病にしていたらミリ耐える試合が多かったのでガチ特化
S : 申し訳程度の振り切り。201は確保したくてここまで振るなら準速でいいやという気持ち
H : あまり
今期はこいつの鉄蹄光線に命を懸けていた。外したら即負けだったが気にしないようにしていた。今期1回も鉄蹄光線は外さなくて神だった。岩雪崩は結構外してたけどな！
イエッサンカメックスの選出を躊躇う相手に対してアド取れすぎポケモンだったため、シナジーの良さを感じていた。その中でも一撃でサイクルを破壊する鉄蹄光線が輝いていた。
この役割を果たす上では通常メガルカリオとの差別化が必要と思われるが、今回は波動の防護による対ミミッキュ性能、メガゲンガーに対して上から悪の波動を叩き込める点を高く評価してZの採用。
臆病CSで使っていた時に1%2%で耐えられて負けて発狂する経験を4回ほどしたので控え目で採用したら、意外とS遅くて困ることがなくて火力も十分あって使いやすかった。151族ミラーとスカーフイダイトウと最速メガマフォクシーにだけ怯えることになるが、それ以外にさらに強くなるなら別によくね？と途中から思った。
初手から鉄蹄光線をぶっ放すドパガキムーブが結構強かったので癖になりそう。
余談だが、グラスフィールドがあると地震に耐性を付けることができる他に、鉄蹄光線を2回打ってもHP回復のおかげで耐えるという面白いシナジーを発揮している。

C特化メガルカリオZの波動弾+ステロを1%で耐えた(H32振りでも確定)メガセグレイブ使い出てこい。お前強すぎ。

イエッサン　NN クロワッサン

調整意図
HB : A182ガブリアスの地震12/16
C : 11n　オボンを持たないアシレーヌを2発で倒せる火力を重視。
S : 後述するカメックスと一致するSライン
フィールドの魔術師その2
先制技を拒否できるというだけでかなりアド取れまくりなので、前期からイエッサンは強いなと思っていた。
カメックスで勝つことに重きを置いていたので、先制技による縛りから守護れるようにフィールドターンを伸ばせるグランドコート。
もはやイエッサン+カメックスは擦られすぎて話すことはないのだが、今回は一つだけ工夫したポイントがあるのでそれを紹介しようと思う。
Sラインについて、カメックスが殻を破るかどうかの選択をする際に上から動くか下から動くかがとても重要になる場合がある。下から動くなら殻破りたい。上から動くなら対面突破したい。
そんな状況に置かれたときにイエッサンとSラインを一致させることでカメックスより早いか遅いかを判別できる。同速は知らないとさせてほしい。
イエッサンの耐久振りに関していろいろと議論の余地はあると思うが、私個人の見解としては、あまりイエッサンが長いターン居座るのは好ましくないと考えているため、あまりがっつりは振らない。
また、技構成に関しても癒しの願いは必須だと感じており、癒しの願いを採用するなら技この4つに帰着するだろうなという印象。
準速キラフロル、準速セグレイブ、準速セグレイブ抜きのいくつかのポケモンが厳しいのではないかと思ってS実数値143にしたのだが、準速ミミッキュ、準速リザードンの方がよっぽど警戒するべきなので、正直執筆中の今はS実数値131~143は気にせずS実数値130でもいいのではと思っている自分がいる。
改善案として143-×-92-165-116-130(8-0-17-25-1-15)
HB : A164エースバーンの火炎ボール13/16耐え、A200ガブリアスの地震14/16耐え
HD : C202メガキラフロルのヘドロウェーブ13/16耐え
H : 16n-1

カメックス　NN 7th Trigger

調整意図
S : 殻を破る後最速龍舞メガボーマンダ抜き
C : 火力が足りないので全て振り切り
H : 奇数
B : 端数。Dだと殻破った後に切り捨てになるため損しないB側
フィールドの魔術師その3
このポケモン自身はフィールドを展開しないが、フィールドを活用するのでまあ魔術師と名乗っていいでしょう。
もともと控え目で使っていたが、イエッサンとSラインを調整したい、イエッサンがS130だと心許ないと感じたため臆病にして143で一致させた。
今考えると臆病にしたことで火力足りない感すごいし耐久振りたかったなと思ったので次使うなら多分控え目。ミラーまで意識すると最速にしたいだろうけど、ゴリランダーいるうちは必要ない。
で、このポケモンは制圧力まじですごいのでとても使いやすかった。そもそも壁などを使って起点作成するポケモンが多い中でこいつはマンダの捨て身タックルすら起点にできてしまうから本当にすごい。
最終日はやらなかったが、ゴリランダーのグラスフィールドを使って草タイプの大地の波動も打てると頭に入れておくとアシレーヌすら殻を破らなくても破壊できるようになる。バグ。
こいつが一番嫌なのは実はスケショガブリアス。

ガブリアス　NN フカヒレ

調整意図
S : フラエッテを意識して最速
A : 耐久に振る理由が途中からなくなったため振り切り
B : 端数
とりあえず困ったらガブリアス投げていた。
イエッサンカメックスの並びは瞑想フラエッテが実はどうしようもないため、削ったら最低限何とかなる&ワンちゃん対面勝てたらいいなの精神で最速。HBSで使っていた時期もあったがメガグソクムシャの吸血を結局2耐えしないこと、ガブのスケショ4発耐え調整が5発当てられてまったく意味をなさずあったまっていたことからAS。
剣舞は壁構築に対する抵抗&起点回避のために採用したが、これだとリザードンが重くなってしまうため、大人しく岩石封じでよかったかもしれない。

選出率圧倒的1位(数えていないため他の選出率はわかりませんごめんなさい)

アシレーヌ　NN プリマステラ

調整意図
HB : A216メガボーマンダの捨て身タックル13/16耐え
S : 準速ドドゲザン抜き + 最速メガグソクムシャ抜き + 準速以外のミラーS勝てるライン
補完枠だが汎用性が高いため意外と投げることに抵抗がなかった。もともとサーフゴーをドヒドイデ対策としていたところ、黒い霧メガカイリューとかいうポケモンに完封されて負けたので、このカイリューごと貫けるポケモンいないかなと探していたところ白羽の矢が立った。過剰に役割を与えすぎると過労死するが、自然な受け崩しという点はきちんと役割をこなしてくれた。地味にアーマーガアに耐久される展開を阻止することができて面白かった。
努力値だが、本当に余裕がない。本当はHBもっと欲しかったしCもっと伸ばしたかった。
アシレーヌに対してドヒドイデが来た時には身代わり+サイコノイズで回復を阻害しつつサイコノイズ+ムーンフォースでちまちま削っていく。サイコノイズはPPがきついので連打しない。
ガブアシレが入ると見た目引き締まっていいよね。

選出
メガルカリオZ + ガブリアス、ゴリランダー、アシレーヌから2匹

ガブリアス + イエッサン + メガカメックス

の2軸が基本。体感ではカメックスで積める展開が多かったのでカメックスを多めに投げていた。
例外的なパターンとして、メガスターミーがアイススピナーでフィールド解除してくるので、初手カメックスを合わせて殻を破ったりしていた。

重いポケモン
・スケショガブリアス
イエッサン対面でスケショされるとカメックスが殻を破ってもスケショ地震で負けるため相手したくない。

・アーマーガア
構築内にアーマーガアを迅速に処理できるポケモンがいないためある程度お祈り要素がいる。

・最速瞑想フラエッテ
HP満タン状態からだと瞑想読みアンコールしても勝てないため事前に削っておく必要がある。

・メガスターミー
アイススピナーでフィールドを破壊してくるやつの中でもゲームを終わらせてくる度が高いやつ。

・エルフーン
当たらなかったが、これ系は処理がもたついてしんどい。

・Aキュウコン
壁展開に対してかなり後手に回るため、キュウコンに気合でルカリオを合わせに行くくらいの気持ちでやる。

・メガ前メガギャラドス
まじで鬼の択勝負が始まる。ここ択だな。

・ウルガモス
まじで使うならガブリアスに岩石封じ入れる。
