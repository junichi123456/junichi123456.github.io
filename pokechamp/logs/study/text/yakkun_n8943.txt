スポンサーリンク

使用ポケモン
メガルカリオZ@ルカリオナイトZ(ひかえめ)はどうのぼうご
HP:24 / 防御:11 / 特攻:9 / 特防:3 / 素早:19
(252表示: HP:188 / 防御:84 / 特攻:68 / 特防:20 / 素早:148)
実数値:169-108-101-212-93-190
はどうだんてっていこうせんしんくうはめいそう

先発要因１です
このパーティーのエース１
ライバロリ産のMZを少し改良したルカリオです
S　最速120族抜き
B　カイリュウ、メガルカリオの「地震」高乱数耐え
D　キラフロル控えめの「だいちのちから」高乱数耐え、メガキラフロルはひかえめは切って立ち回ります
また、ライバロリさんの動画でも紹介していましたが、アシレーヌ対面「めいそう」からの「てっていこうせん」で飛ばすことができます

メガじゃないカイリューは「波動弾」「てっていこうせん」で最悪１＝１取れる

リザードンXがきついブリジュラス、キラフロルに有利で補完が取れてますね

ブリジュラス@しろいハーブ(ひかえめ)がんじょう
HP:2 / 特攻:32 / 素早:32
(252表示: HP:12 / 特攻:252 / 素早:252)
実数値:167-112-150-194-85-137
りゅうせいぐんてっていこうせんステルスロックがんせきふうじ

先発要因２です
このブリジュラスはM3の「かしわ」さんのブリジュラスを参考にしてます
「りゅうせいぐん」は雑に強いので採用
「てっていこうせん」は起点になる前に自主退場できたり、「ラスターカノン」や「りゅうせいぐん」なら耐えると踏んだ相手のポケモンを倒せたりするので採用
先発メガピクシーH振りを上からワンパンすることも
「がんせきふうじ」はリザードンYに有利に立ち回ることができます、またタスキの先発枠に撃てるのが強いため採用、ミミッキュの皮も剥げる
「ステルスロック」は雑に強く、リザードン、カイリュー、裏のタスキを破ることができるので採用です、ラウドボーンがいる場合はほぼ必ず貼ってください
また、からやぶカメックスにラスト出したりも

メガリザードンX@リザードナイトX(いじっぱり)かたいツメ
HP:16 / 攻撃:20 / 素早:30
(252表示: HP:124 / 攻撃:156 / 素早:236)
実数値:169-187-131-135-105-150
フレアドライブかみなりパンチドラゴンクローりゅうのまい

先発要因３です
このパーティーのエース２
裏から出すことはほとんどないです
S　1 舞でMZ抜きです
H　ガブのストーンエッジ、MZガブのパワージェム、Mメタグロスの地震、耐え

ブリジュラス、通常キラフロル、が入っているパーティには出しづらいです
通常では辛いカバルドン、ガブリアスにはふうせんブリムオンでかもれるので全然大丈夫です。ブラッキー、ニンフィアも同様

相手のロトム、アシレーヌ、フラエッテ、グソクムシャ、サーフゴー、イダイトウ、メタグロス、ゴリランダー、マスカーニャ、ガブリアスZ、などに対しては「竜舞」から入ることができる（Mフラエッテ、Mメタグロス、ガブリアスZ、などはメガ前前提）ただし相手の構築による
カイリューはマルスケがなければ舞えます

ガブ、カバ、対面はドラクロから入ってブリムオンに引きます

HB特化リザードンYには1舞「雷パンチ」で耐えられる、対面は勝てるけど注意

ライチュウY対面は「フレアドライブ」で突っ込みます、その後癒しの願いでまひ回復できる

技範囲によって相手の受け崩しが可能で、ルカリオZ、リザードンYに出てくるドヒドイデを崩すこともでき、初手フラエッテから「瞑想」してくるのに合わせ「竜舞」すると相手を一気に崩すことができます
正直こんなことを書いてますけどドヒドイデは全然重く
H6、A30、S30、いじっぱり、の調整だとより、まだドヒドイデに強い、それだと他対面舞うことが難しくなるのでいい調整があれば教えて欲しいです

ブリムオン@ふうせん(れいせい)マジックミラー
HP:27 / 特攻:32 / 特防:7
(252表示: HP:212 / 特攻:252 / 特防:52)
実数値:159-110-115-206-130-44
トリックルームいやしのねがいマジカルシャインマジカルフレイム

HD 　サーフゴーひかえめの「シャドーボール」、C１段階ダウン「ゴールドラッシュ」高乱数耐え、
C　　ガブリアスH２振りを高乱数１発、　　H32振りMグソクムシャ乱数50%、（改良点or立ち回りでカバー）

ふうせんによってルカリオ、リザードンが辛いカバルドン、ガブリアスに一方的に立ち回ることができます

相手のアタッカーに対して切り返せる「トリックルーム」
先発で出したエースを再び使うことができる「癒しの願い」
リザードンを採用しない場合欲しくなる炎打点「マジカルフレイム」特殊に対してトリル貼った前提、上から打つことで打点を奪うことができ、「癒しの願い」で回復したエースの起点を作ることができる
カイリュー、ガブリアス弱点一致技を撃つことができる「マジカルシャイン」

グロス、サーフゴーには注意

枠がないですが正直、エスパータイプ一致技が欲しいです、リザードンXでもドヒドイデに対して強いかと言うと個人的には怪しいところ、改善案求

カバルドン@ゴツゴツメット(わんぱく)すなおこし
HP:32 / 防御:32 / 特防:2
(252表示: HP:252 / 防御:252 / 特防:12)
実数値:215-132-187-79-94-67
じしんこおりのキバあくびなまける

対面性能が高いHBゴツメカバです
説明することはあまりないですが、タイマン性能が高く、構築で重いメタグロス、ミミッキュ、ギルガルド、エースバーン、ミミロップなどに強い、また特にMギャラドスがこの構築重いので誤魔化しもできる
相手のふうせんサーフゴー交代に合わせて「氷の牙」打てると有利に持っていけます
アシレーヌ引きには注意してください、気合いでアシレーヌ引きに合わせて「欠伸」してください

ミミッキュ@いのちのたま(いじっぱり)ばけのかわ
HP:1 / 攻撃:32 / 特防:1 / 素早:32
(252表示: HP:4 / 攻撃:252 / 特防:4 / 素早:252)
実数値:131-156-100-63-126-148
じゃれつくシャドークローかげうちつるぎのまい

普通のミミッキュですね

パーティーで重いイダイトウ、ミミッキュ、ギルガルド、サーフゴー、に対してのミミッキュですね
からやぶカメックスにラスト出したりも
このミミッキュはミラーで弱いですが
H29、A32、B5、いじっぱり、「剣の舞」を「呪い」に変えた型と交互に使ってました
こっちのミミッキュはトリルとシナジーが高く、イダイトウ、ミミッキュ、に対して特に強くでることができます
皮が剥けた後、玉ミミッキュの「影撃ち」玉イダイトウの「アクアジェット」ガブリアスの「地震」なども耐える調整です
Mギャラの１舞なら普通に耐えます
また「呪い」で積みポケモンに争うことができます
ただリザードンYの上を取りずらい、、、正直好みと気分ですね

戦術と解説

戦術ですが、基本は、メガ（先発）＋ブリムオン＋この２体ではきついポケモンに強いポケモン
または、ブリジュラス（先発）＋メガ＋ブリムオンorこの２体ではきついポケモンに強いやつ

ポケモン先発はルカリオZ、ブリジュラス、リザードンX、の３体から選びます
基準は消去法で出していきます
キラフロル、ブリジュラス入りにはリザードンXは出さず、ルカリオZを先発で出します、
基本この2体がいない場合リザードンXで破壊することができますね

リザードン入りには、リザードンX出したいですが、ルカリオZは出すとしても後出し→ブリジュラス先発（初手ブリ、リザ対面、がんせきふうじ→ステルスロック、がんぷうのダメージによっては別技）、となりますね、

メガ先発で１体倒すと次にガブリアスを呼びやすいので、HPを残しブリムオンに引きトリルを展開後、暴れて、「癒しの願い」でメガを再展開（場合によってはメガ再展開しないorメガ以外に使う）
リザードンX、ミミッキュ、カバルドン、ブリジュラス、はトリル中で暴れることもできる

このように暴れた後
ミミッキュ、カバルドン、ブリジュラスで詰めていきますね

ブリジュラスの「てっていこうせん」＋ルカリオZ、1積み「てっていこうせん」で、サーフゴーをゴリ押しもできますw

戦術解説は異常です！
最後に、、、まぁ、わかってると思いますが「てっていこうせん」２体採用は意味わかんないですが、メガフラエッテはマジで嫌いなんでしかた無いですね♡
