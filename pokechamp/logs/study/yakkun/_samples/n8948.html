レンタルチーム有

イエッサン♂バンギラスグレンアルマメガカメックスメガメガニウムオオニューラ

初めましてカナと申します。私はチャンピオンズのスマホ版がリリースされた所から始めた超初心者なのですが今シーズンで初めてオリジナルの構築でマスターに到達できたので投稿したいと思います。初めて構築記事を書くので至らぬ点が多々あるかと思いますがどうぞ最後までお付き合いください。まだまだ荒削りなパーティーなのでアドバイス等ありましたらコメントしていただけたらと思います。

スポンサーリンク

使用ポケモン

  • イエッサン♂@こだわりスカーフ(おくびょう)サイコメイカー
  • HP:2 / 特攻:32 / 素早:32
    (252表示: HP:12 / 特攻:252 / 素早:252)
  • 実数値:137-76-75-157-115-161
  • ワイドフォースマジカルシャインマジカルフレイムトリック

典型的なイエッサン♂です。選出率は100％です。上からワイドフォース打つだけで大抵相手が倒れていきます。あく技やむし技を持ってそうなポケモンが来たらおとなしく引きましょう。カバルドンなどの変化技を使う相手にはトリックでスカーフを押しつけて詰ませてやりましょう。

  • バンギラス@ヨプのみ(いじっぱり)すなおこし
  • HP:32 / 攻撃:32 / 防御:1 / 特防:1
    (252表示: HP:252 / 攻撃:252 / 防御:4 / 特防:4)
  • 実数値:207-204-131-103-121-81
  • いわなだれはたきおとすれいとうパンチまもる

メガリザードンY選出抑制として採用しました。仮に出てきても天候取り返せるしHに振ればメガリザードンYの特化ソーラービームを94%の確率で耐えます。ストーンエッジではなくいわなだれを採用しているのは命中不安が怖いのと仮にメガリザードンXだった時でもいわなだれ＋まもるの砂ダメである程度抗えるからです。オボンのみだと不意のかくとう技で吹っ飛ぶ時があったのでヨプのみを持たせることにしました

  • グレンアルマ@きあいのタスキ(おくびょう)くだけるよろい
  • HP:2 / 特攻:32 / 素早:32
    (252表示: HP:12 / 特攻:252 / 素早:252)
  • 実数値:162-72-120-177-100-139
  • アーマーキャノンワイドフォースみちづれエナジーボール

メガグソクムシャを絶対に許さないポケモンなのですが、完全なる見せポケと化しました。4枠目の技はお好みです。自分もここは何を入れたらいいかよく分かっていません。アドバイス募集中です。

  • メガカメックス@カメックスナイト(ひかえめ)メガランチャー
  • HP:2 / 特攻:32 / 素早:32
    (252表示: HP:12 / 特攻:252 / 素早:252)
  • 実数値:156-110-140-205-135-130
  • みずのはどうあくのはどうれいとうビームからをやぶる

この構築の一体目のメガ枠となります。一回殻破れればたいてい破壊できます。メガボーマンダも上かられいとうビームで倒せます。逆に言えば殻破れないと普通にメガリザードンYに倒されるので上手いこと殻破れるように立ち回りましょう。

  • メガメガニウム@メガニウムナイト(ひかえめ)メガソーラー
  • HP:2 / 特攻:32 / 素早:32
    (252表示: HP:12 / 特攻:252 / 素早:252)
  • 実数値:157-100-135-214-135-132
  • ソーラービームウェザーボールマジカルシャインだいちのちから

二体目のメガ枠になります。採用理由はイエカメニューラの並びだとメガグソクムシャがしんどかったからです。上から特殊炎技打ちつつ裏にいがちなポケモンにも打点あるポケモンいねーかなーと悩みながらボックス見て思いつきました。選出率はカメックスよりは劣りますが選出画面でグソクムシャが見えたら投げていました。ただメガ前はむし技が弱点なのでだれか一体に犠牲になってもらうか先発で出すかになると思います。

  • オオニューラ@サイコシード(いじっぱり)かるわざ
  • HP:2 / 攻撃:32 / 素早:32
    (252表示: HP:12 / 攻撃:252 / 素早:252)
  • 実数値:157-200-80-54-100-172
  • フェイタルクローインファイトいわなだれアクロバット

非メガエースです。大抵こいつとイエッサン♂で破壊できます。選出率はほぼ100%でした。アクロバットを採用している理由はイエッサンのが倒しきれなかった相手を倒しきる時に無効にされないのとインファイトで耐久下げちゃうのがもったいないなと思ったからです。途中までいわなだれの枠をじごくづきにしていたのですが、これはサーフゴーに打点がなさすぎてそうしていました。ただメガカメックスにあくのはどうを覚えさせているしいいかということでメガリザードンY対策のいわなだれに変えました。どっちが正解か分かっていません。アドバイス募集中です。

戦術と解説

基本的には先発イエッサン、その次は大体カメックスで殻破って戦って、倒されたらイエッサンでサイコフィールド再展開した後かるわざオオニューラで一層という流れです。選出画面でグソクムシャが見えたら先発メガニウムでメガシンカし、やられたらイエニューラで戦っていくという感じで戦っていました。リザードンが見えたらオオニューラではなくバンギラスを選出していました。
