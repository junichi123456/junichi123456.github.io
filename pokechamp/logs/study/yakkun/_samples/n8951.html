スポンサーリンク

使用ポケモン

  • メガリザードンY@リザードナイトY(ひかえめ)ひでり

    (252表示: HP:252 / 防御:100 / 特攻:164)

  • かえんほうしゃソーラービームりゅうのはどうがんせきふうじ

対面つよい初手投げ安定型メガリザードンYです。
現環境のメガリザードンYは初手ステルスロックを巻きにくる
ブリジュラスカバルドンエンペルトラグラージミミズズなどを狩れるため、初手投げおすすめです。

がんせきふうじ
先発で勝てる幅を広げられます。
ミミッキュ対面で打ち、ばけのかわをはがしつつ、次で上から倒せます。
また、初手のきあいのタスキ持ちっぽい相手との対面で打ち、確実に対面勝ちできたり、
メガリザードンYウルガモスに4倍弱点で対面勝ちできるなど、強みは多いです。　　
調整意図
HCベースの残りBです。
Sはトリル下で確実にガブリアスの上を取れる無振りです。
先発メガリザードンYからブリムオンでトリックルーム、いやしのねがいを打つので、トリル下で動くことが多いです。
Cは、
かえんほうしゃでブリジュラスH32を確定1発、
ソーラービームでウォッシュロトムH32を確定1発
のラインです。
HBは一応メガボーマンダA32補正込のすてみタックル確定耐えくらいです。

  • ドレインキッスギガドレインいやしのねがいトリックルーム

ステルスロック対策枠です。

役割対象
対面で勝てるステロ撒きのガブリアスカバルドンラグラージバンギラスに即後投げし、ステロをマジックミラーで跳ね返しつつトリックルームを張り、自分で打ち合う役割です。
またいやしのねがいによる先発回復も強みです。
Cも高いため、トリル下であれば主に
ガブリアスセグレイブバンギラスブラッキーなどに強く出られます。
またマジックミラーであくびループをきれるため、カバルドンラグラージエンペルトなどにも強く出られます。
調整意図
ガブリアスカバルドンラグラージバンギラスなどが役割対象なのでHBです。
特化にすることで、ガブリアスのつるぎのまい1積みA特化補正込じしんを乱数6.25%で受けられます。
技構成
吸収技で場持ちを良くし、カバルドンラグラージガブリアスバンギラスブラッキーなどからの変化技や設置技をなるべく拒否できるようしています。
また、長く対面できるため、いやしのねがいをローになってから確実に打つことができます。
技選択候補は、
ギガドレインをマジカルフレイムです。
ギガドレインはカバルドンラグラージ対面意識、
マジカルフレイムはいやしのねがい前の起点づくりやへの打点という感じです。

少し前までは、アーマーガアハッサムのきりばらいが多かったですが、特殊炎技を打ってくるメガボーマンダメガガブリアスZイエッサン♂の増加できりばらいを打ちづらい場面が多くなったため、現環境においてはブリムオンのほうが強いと思います。

  • カバルドン@ゴツゴツメット(のんき)すなおこし
  • HP:32 / 防御:32 / 特防:2
    (252表示: HP:252 / 防御:252 / 特防:12)
  • 実数値:215-132-187-88-94-60
  • じしんステルスロックあくびなまける

地面枠採用の物理受けクッションです。

役割対象
構築で重かったメガカイリューメガライチュウYパーモットメガグソクムシャウルガモスメガリザードンYキラフロルドヒドイデメガボーマンダバンギラスラウドボーンなどに強いです。
また、トリックルーム展開後で面倒だったミミッキュに対しても強く出られます。
あくびループをして削られたあとにブリムオンのいやしのねがいで全快させる動きも強かったです。
技選択候補はあくびをふきとばしです。
  • ウォッシュロトム@たべのこし(ひかえめ)ふゆう
  • HP:32 / 防御:1 / 特攻:25 / 特防:8
    (252表示: HP:252 / 防御:4 / 特攻:196 / 特防:60)
  • 実数値:157-76-128-165-135-106
  • ハイドロポンプボルトチェンジみがわりわるだくみ

メガリザードンYがドヒドイデブラッキーを連れてくるため、そこのピンポイントメタ兼一応クッション要員です。

調整意図
Cは、
わるだくみ1積み10まんボルトで
ブラッキーH32を確定2発(55.5%〜65.8%)
ドヒドイデHD32補正込を確定1発(100.6%〜119.8%)
HBは、ブラッキーA0のイカサマを
ウォッシュロトムのみがわりが確定耐え(21.0%〜24.8%)
残りD

参考元→チャンピオンズ育成論/48

  • サザンドラ@こだわりスカーフ(ひかえめ)ふゆう
  • HP:2 / 特攻:32 / 素早:32
    (252表示: HP:12 / 特攻:252 / 素早:252)
  • 実数値:169-112-110-194-110-150
  • あくのはどうりゅうせいぐんかえんほうしゃきあいだま

使いやすいスイープ枠です。

役割
メガメタグロスとのタイプ補完がよく、一貫技がのみなので、サイクルを回しやすいです。
また、構築で重かったイダイトウ♂イエッサン♂メガアブソルZラウドボーンメガカイリューなど、対策の難しいポケモン達に強いです。
一貫の取りやすい特殊打点をタイプ一致で打てるのも、スイープ枠として優秀です。
調整意図
Sは、メガガブリアスZメガルカリオZメガアブソルZ最速抜きです。
Cは特化にし、残りHとしています。
技構成はきあいだまを採用しています。
メガメタグロスがきついに受け出した時の打点や、
メガリザードンYがきついバンギラスへの打点意識です。これにより選出の幅は広がります。
他候補は、りゅうのはどう、とんぼがえりです。
  • メガメタグロス@メタグロスナイト(いじっぱり)かたいツメ
  • HP:26 / 攻撃:32 / 素早:8
    (252表示: HP:204 / 攻撃:252 / 素早:60)
  • 実数値:181-216-170-112-130-138
  • バレットパンチじしんかみなりパンチれいとうパンチ

メガリザードンYがきつそうな時に、雑にサザンドラと一緒に投げます。

メガ枠の補完
現環境でメガメタグロスがきつい
メガグソクムシャメガクチートドドゲザンダイケンキ(ヒスイ)サーフゴーメガゲンガーゲッコウガマスカーニャメガリザードンYウルガモスなど全員にメガリザードンYが有利を取れます。
逆にメガリザードンYが対面できつい
キラフロルセグレイブメガボーマンダオオニューラメガフラエッテドヒドイデメガライチュウYバンギラスアシレーヌギャラドスなどに対してメガメタグロスが有利を取れます。
ガブリアスメガカイリューミミッキュなども無理やり対面で突破できるため、メガ枠2体の補完はいいです。
調整意図
Sは、ブリジュラス準速、ゴリランダー準速抜きで、A特化の残りHです。
Sは、技構成次第ではサーフゴー準速抜きまで落としたり、セグレイブ準速、キラフロル準速、ウォッシュロトムヒートロトム準速まで上げたりするのもいいと思います。
技構成は、スタンダードな型からサイコファングを抜いてれいとうパンチにしている感じです。ここはお好みでしっくり来たやつを使ってください。

戦術と解説

基本選出

基本的にメガ枠の選出は、
メガグソクムシャがいたらメガリザードンY、メガライチュウYがいたらメガメタグロス確定選出で、
あとは相手の取り巻きの次第です。

メガリザードンY+ブリムオン+@1
ガブリアスorカバルドン++α
に出します。一番多い選出方法になっています。
@1は、
イダイトウ♂イエッサン♂がいるならサザンドラ、
ブラッキードヒドイデがいるならウォッシュロトム
確定選出です。
メガメタグロス+サザンドラ+@1
イエッサン♂+メガカメックス+オオニューラに出します。
オオニューラにメガメタグロス、イエッサン♂にサザンドラが強いです。
@1は、メガカメックスにからをやぶるをする隙を与えづらそうなポケモンが好ましいです。
カバルドン+メガメタグロス+サザンドラ
カイリュー+キラフロル+メガルカリオZに出します。
たまにこの並びでもメガカイリューになってくることがあるため、相手の初手キラフロルメガカイリューに両対応するための初手カバルドンです。
相手のキラフロル入りには、基本メガメタグロスを投げましょう。その場合は初手キラフロルorメガメタグロスの選択ってかんじです。

立ち回り

対面構築なので、基本はサイクルで大丈夫です。
ただメガリザードンYブリムオン選出時のギミックが少し複雑です。
まずカバルドンガブリアスラグラージバンギラスが来たら、ブリムオンに引きます。
着地したら基本即トリックルームでいいんですが、相手の裏と自分の裏的にトリックルームが利敵になると感じたら、貼らない選択肢もあります。そこの判断が難しいため、練度が必要です。
あとはガブをブリムオンで見る形を作りながら、ブリムオンをで見に来るならメガリザードンYに引き、そこでトリックルームが残っていれば、仮にガブリアスに引かれても対面勝ちすることができます。

長くなってしまいましたが、ここまで見ていただきありがとうございました！この構築はパワーは相当高いと思っています。レンタルチームも載せておくので、ぜひ使ってみてください！
