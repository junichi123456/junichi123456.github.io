こんばんは。ガラルヤドキングを使いたいと思い作りました。この構築でレートが爆盛り出来たので紹介します。有利不利なポケモン、主な運用方法、交換案なども含めて紹介します。まだまだ初心者なので、個体値調整案や改善案などがございましたらバシバシご指導してください

スポンサーリンク

使用ポケモン

  • メガミミロップ@ミミロップナイト(ようき)きもったま
  • HP:2 / 攻撃:32 / 素早:32
    (252表示: HP:12 / 攻撃:252 / 素早:252)
  • 実数値:142-188-114-66-116-205
  • ねこだましトリプルアクセルとびひざげりつるぎのまい

ヤドキング(ガラル)と相性が良いと思い採用

運用

挨拶がてらにねこだましするのは鉄則です。ですがゴツゴツメット持ちには気をつけましょう

有利(個人的に)

最速なので最速ライチュウや準速メガZ組の上を取れます。特性でいかく無効なので運さえ悪くなければメガボーマンダも1発で倒せます。ねこだましのおかげで大体のポケモンはタスキ剥がして倒せます

重いポケモン

HBゴツメ型のポケモンがキツイです(ウルガモスガブリアスギャラドス)物理受けには歯が立たないです。

交換案

ガブリアス(Z型)メガガルーラゲッコウガ

  • ヤドキング(ガラル)@シュカのみ(おだやか)さいせいりょく
  • HP:32 / 特攻:14 / 特防:20
    (252表示: HP:252 / 特攻:108 / 特防:156)
  • 実数値:202-76-100-144-165-50
  • さむいギャグどくどくかえんほうしゃみらいよち

この構築の要。対面操作とクッションを担ってます

運用

交代のクッションとして使用。後攻さむいギャグで安全に交代したり、相手の交代先にみらいよちで圧をかけたりします。また、居座ってどくどくを撃つのもあり。状況によって使い分けて下さい。半減木の実込みでガブリアスの地震を確定で1耐えします。天候パなどには必ず選出してます。ウルガモスを一緒に選出してる時はさむいギャグの使用を考える必要があります

有利

大体の特殊技を安全に受けられます。ハラバリー』ブラッキー』などの耐久にはどくどく』をつけられ、ドヒドイデ』にはみらいよち』→さむいギャグ』で後続で倒すことが出来ます。アーマーガア』も安全に焼けます。またペリッパーやメガリザードンYの天候もさむいギャグで塗り替えられるため非常に有利です

重いポケモン

ブリジュラス』には何も出来ません。サーフゴー』ルカリオ』には削ることは出来ても倒せません。ガブリアス』にも確定2発で落ちます。イダイトウ♂』ドドゲザン』にも抗えずやられます

改善案

なまける』を搭載したら居座り性能が上がるかも

  • メガギャラドス@ギャラドスナイト(いじっぱり)かたやぶり
  • HP:2 / 攻撃:32 / 素早:32
    (252表示: HP:12 / 攻撃:252 / 素早:252)
  • 実数値:172-227-129-81-150-133
  • じしんパワーウィップゆきなだれりゅうのまい

サブメガ枠。ロトム系統の殲滅と草、地面技枠の確保のため採用

運用

相手に悪打点があったり、じしんを透かしたり、威嚇を入れるため、メガを切るのは慎重に。あとはテンプレ通りの使い方です。

有利

メガをしなければオオニューラゴリランダーエースバーンに威嚇込みで有利です。メガをしたらミミッキュマフォクシーロトム系統に有利です。また、メガジュペッタのアンコールをタイプ特性で無効化できるため起点に出来ます

重いポケモン

ライチュウルカリオパーモットメガミミロップサーフゴーが厳しいです。ブリジュラスは倒せてもかなり削られます

改善案

たきのぼり採用でウルガモスが楽になります。交換枠は思いつきませんでした

  • サーフゴー@ふうせん(ひかえめ)おうごんのからだ
  • HP:32 / 防御:2 / 特攻:32
    (252表示: HP:252 / 防御:12 / 特攻:252)
  • 実数値:194-72-117-203-111-104
  • シャドーボールきあいだま10まんボルトわるだくみ

上記のポケモンで突破が難しいブリジュラスやHBゴツメギャラドスのために採用

運用

カバルドンやブリジュラスが見えたら選出してます。ブリジュラス突破のため、鋼技を捨ててきあいだまを採用しました

有利なポケモン

ブリジュラスギャラドスカバルドンには極めて有利です。キュウコン(アローラ)も2発で落とせますので、起点にするのもアリかと

重いポケモン

メガミミロップやウルガモスに弱いです。テンプレ型なので対策されやすいかも

  • ウルガモス@オボンのみ(ずぶとい)ほのおのからだ
  • HP:32 / 防御:32 / 特攻:2
    (252表示: HP:252 / 防御:252 / 特攻:12)
  • 実数値:192-72-128-157-125-120
  • ほのおのまいちょうのまいむしのさざめきあさのひざし

炎枠でなんとなく入れました。ですがこの構築で一番2タテ、3タテを量産してます。積ませ性能が異常に高いです

運用

積んで殴る。テンプレの使い方です。メガメタグロスグソクムシャの接触組には接触的に受け出ししましょう。ヤドキング(ガラル)の雪とあさのひざしは相性最悪ですが、相手によって回復量が左右するギガドレインよりは信用出来るので搭載してます

有利

大体の特殊アタッカーに有利ですがアシレーヌは例外です。接触技が主なポケモン達にも有利です

重いポケモン

ステロ、これに尽きます。最近はガブリアスに岩技を搭載してる型が増えてるので用心する事を勧めます

交換案

ねばねばネット枠でオニシズクモもアリです

  • エースバーン@こうかくレンズ(ようき)リベロ
  • HP:2 / 攻撃:32 / 素早:32
    (252表示: HP:12 / 攻撃:252 / 素早:252)
  • 実数値:157-168-95-76-95-188
  • かえんボールうちおとすふいうちコートチェンジ

ステロ対策で採用。メガリザードンYやウルガモスの対策でうちおとす』を搭載してます。選出回数はゼロです。ここは別のポケモンに交換してもいいと思います

戦術と解説

選出

基本選出はヤドキング(ガラル)メガミミロップウルガモスの並びです。ただ、ステロ要因(ブリジュラスカバルドンガブリアスラグラージ)がいる場合はウルガモスの枠をサーフゴーに変え初手出しします。メガミミロップの枠は相手の構築に合わせてメガギャラドスと使い分けて下さい

戦術

基本的な対面で動きます。そこにヤドキング(ガラル)をクッションにしながら対面操作を行います。ヤドキング(ガラル)が裏にみらいよちで圧をかけたり対面に耐久型にどくどくで耐久を縛ったりします。ヤドキング(ガラル)』の動きで勝敗がかなり決まります。引く時は後攻さむいギャグ』で引くのが良いですが、ウルガモスを選出してる時は少し考える必要があります(雪状態であさのひざしの回復量が半減するため)

まとめ

基本的な対面構築。ヤドキング(ガラル)の動かし方が肝心です。技やポケモンをカスタマイズするのも良いと思います。アドバイス等是非お申し付けください
