# Star Crusade 再現版(非公式)

ZiMAD の「Star Crusade CCG」(2015〜2017)をスマートフォンのブラウザで遊べるよう再現したファン作品です。

- 遊ぶ: `starcrusade/index.html` を開く(GitHub Pages なら `https://<user>.github.io/starcrusade/`)。一度開けば Service Worker によりオフラインで動作し、ホーム画面に追加するとアプリのように起動できます。
- 機能: CPU 対戦(相手はランダムデッキ)、同じ端末での2人対戦、デッキ構築、カード図鑑、勢力ガイド、戦績、文字サイズ変更、自動セーブ+3スロット、データの書き出し/読み込み。
- 資料: [RESEARCH.md](RESEARCH.md)(勢力固有能力の調査と利用法)、[CARDLIST.md](CARDLIST.md)(全カードの一覧と確認度)。

## カードの確認度

原作のカードデータは失われているため、各カードに確認度を付けています。

| 表示 | 意味 |
|---|---|
| 検証済み | 公式告知・パッチノート・開発者投稿で文面と数値を確認 |
| 一部確認 | 名称と一部の数値/文面を確認。残りは再構成 |
| 名称のみ | 名称と勢力の文脈のみ確認。効果はゲーム用に再構成 |
| 補完 | 資料で確認できない仮称カード |

## ファイル構成

- `js/data.js` カード・モジュール・キーワード・勢力データ(カードの追加・修正はここ)
- `js/engine.js` ルールエンジン(状態は JSON で保存可能)
- `js/ai.js` CPU(1手先評価の貪欲法)
- `js/guide.js` 勢力ガイド・遊び方・出典
- `js/app.js` 画面
- `sw.js` オフラインキャッシュ(ファイルを更新したら `VERSION` を上げる)
