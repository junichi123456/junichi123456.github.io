# RC造オフィスビル — 2D設計図（CAD）＋簡易3Dモデル

`spec.yaml`（設計仕様書）をもとに、建築基準法と関連法令に沿った**基本設計図一式（DXF/PDF）**と、
同じ建物モデルから起こした**簡易3Dモデル（glTF）**を自動生成します。

- ビューア: [`index.html`](index.html)（GitHub Pages では `/rc-building/`）。3D表示・図面ギャラリー・法規チェック表
- 図面: `dist/dxf/*.dxf`（CAD用・シート単位）、`dist/drawings.pdf`（A3 全17枚）、`dist/png/`
- 3D: `dist/model.glb`（Y-up・m 単位。部位と階ごとにノードを分割）
- 法規チェック: `dist/LEGAL_CHECK.md`（57項目、数値はすべてモデルから算出）

## 作図の考え方（CAD）
- モデル空間に実寸 1:1（mm）で作図し、図枠・文字・記号は縮尺に合わせて拡大して配置（A3）
- 線の使い分けは JIS A 0150（建築製図通則）に準拠：切断面は太線＋ハッチング、見え掛かりは細線、
  通り芯は一点鎖線、敷地境界は二点鎖線、隠れ線は破線
- レイヤは A-（意匠）／S-（構造）／G-（図枠）に分割。文字は IPA ゴシック
- 平面・立面・断面は、3D の部材ボックスを切断・投影し、手前の部材で隠れる線を消して作図
  （`src/views.py`）。図面と3Dモデルは必ず一致する

## 再生成
```
pip install ezdxf matplotlib shapely trimesh pyyaml
python3 src/build.py
```
`spec.yaml` の敷地・スパン・階高・部材寸法などを変更すると、図面・法規チェック・3Dがすべて更新されます。

## 注意
これは計画段階の検討図です。構造計算（ルート1 等）、日影規制などの条例、省エネ適合性判定、
消防協議は「要確認」として残しています。建築確認申請には、建築士による設計・検証が必要です。
