## 2. 敷地所要面積の試算（建物＋駐車場＋塀）

建物内寸17m角・駐車3台を前提に、擁壁離隔と塀の位置から敷地の必要寸法を逆算した結果。

| 項目 | 数値 |
|---|---|
| 建物外寸 | 17.74m角（RC250＋外断熱100＋外装仕上げ20mm概算）／建築面積 314.7m² |
| 北側帯 | 擁壁＋離隔5.0m → 5.37m |
| 東側帯 | 擁壁＋離隔2.0m → 2.37m |
| 南側帯 | 外壁から塀まで最低2.0m |
| 西側帯（駐車3台） | 車路3.0m＋駐車奥行5.5m＝8.5m（3台の間口7.5mは建物南北辺17.74m内に収まる） |
| **必要敷地寸法（最小）** | 南北 約25.1m × 東西 約28.6m |
| **必要敷地面積（最小）** | **約718.4m²（217.3坪）** |
| 現況敷地（想定700m²）との差 | **約18m²不足** |

**要点**
- 駐車台数を6台→3台に減らしても、必要面積はほぼ変わらない。東西寸法を決めているのは駐車の「間口（並び方向）」ではなく「奥行（車路＋駐車長）」であり、台数を減らしても奥行自体は変わらないため。
- 北・東の擁壁離隔（がけ条例対応）が敷地面積の消費要因として最も大きく、駐車場より優先度が高い制約。
- 圧縮の余地：①駐車の車路・奥行を詰める（車路3.0m→2.7m、奥行5.5m→5.0m程度で必要面積は現況700m²内に収まる試算）、②駐車を南面に分散配置する、③北・東の離隔自体を行政協議で見直す。
- 敷地が正方形でない場合、この矩形近似の数値は実際と乖離する。実測図の確定が必須。



| 項目 | 内容 |
|---|---|
| 基準地盤面（GL） | **南側道路レベルを基準**（切土方式を採用、盛土は行わない） |
| 北側処理 | RC擁壁（がけ条例対応、構造計算・工作物確認申請が必要）＋擁壁から5m離してH1.8mのRC塀 |
| 東側処理 | RC擁壁（同上）＋擁壁から2m離してRC塀 |
| ピロティ | **不採用**（主屋の低層部を駐車場等の開放階にする案は見送り） |
| 半地下 | 不採用（南側道路基準の切土案を優先したため見送り） |
| 1階床レベル | 南側道路面より最低30〜45cm上げる（内水・逆流に対する保険） |
| 外周仕上げ | 北・東の低い側、腰壁部分は防水性重視の仕上げ（タイル・石張り等） |
| 排水計画 | 排水管に**逆流防止弁**を設置。**強制排水ポンプ**（非常電源付き）を機械室に計画 |
| 地盤調査 | 河川近接につき軟弱地盤・高い地下水位を想定。ボーリング調査必須（未実施） |
| 施工留意 | 掘削深3〜4mの仮設山留め、湧水対策の検討が必要（施工計画段階） |

| 壁厚 | RC250mm（構造躯体） |

## 5. 温熱・空調計画

| 項目 | 内容 |
|---|---|
| 室内環境目標 | **夏：室温26℃／湿度45%RH　冬：室温22℃／湿度60%RH**（通年、季節で温度のみ切替） |
| 絶対湿度 | 夏9.58g/kg・冬10.05g/kg で年間ほぼ一定（設計上の大きな利点） |
| 露点温度 | 夏13.2℃／冬13.9℃ |
| 空調方式 | 全館空調（ベンティエール／デシカ等）。**全熱交換換気が必須**（顕熱交換型では潜熱負荷が3倍以上に悪化） |
| 機械室 | 西系統・東系統の2系統に分割。各系統に全熱交換ユニット・調湿ユニット・加湿ユニット・排煙機を集約 |
| 参考負荷（延床578m²規模時） | 暖房 約8.2kW／冷房顕熱 約6.1kW／加湿 約57L/日／除湿 約85L/日（全熱交換70%回収想定） |
| UA値目安 | 約0.25〜0.29 W/m²K（HEAT20 G3水準相当） |
| 躯体熱容量・時定数 | 時定数 約22日（外気の週単位変動が室温にほぼ現れない） |

## 6. 外皮・開口部

| 項目 | 内容 |
|---|---|
| サッシ | トリプルガラス・樹脂枠（またはアルミ樹脂複合可、露点13℃台に対し余裕あり）、Low-E |
| UVカット | 最優先（99%程度が現実的上限、"0%取得"は物理的に不可能） |
| 窓の可動方式 | **FIX窓を基本とする**（転落防止と排煙の両立が困難なため、可動サッシに頼らない方針に確定） |
| 換気の法的根拠 | 全館空調（機械換気）が建基法28条2項ただし書・令20条の2の技術基準を満たす設計とし、開閉窓に依存しない |
| 排煙の法的根拠 | **機械排煙設備**（令126条の3）で対応。1階LDK・居室A・居室B・ジムの4室で確定（各室 床面積×1m³/分以上の排出能力が目安。合計 約87.5m³/分、実務上120〜150m³/分クラスを選定） |
| 排煙バックアップ電源 | 専用回路として蓄電池（10〜16kWh級）を想定。太陽光カーポートと連携 |
| 採光基準 | 有効採光面積＝床面積の**1/7＋1ポイント（15.29%）** を設計基準値に設定。採光補正係数K=3.0（敷地に余裕があり上限値が適用される見込み、要確認） |
| 1階 実ガラス面積（確定） | LDK：4.06m²（うち+2.0m²は追加分）／居室A：0.70m²／居室B：0.70m²／ジム：1.65m² |
| 2階窓仕様 | **未確定**（1階と同方針を延長するか、個別検討が必要） |

- ジム（1階）とシアター（2階）は北西セルに完全積層。北面は開口最小・擁壁側で、遮音上も法規上も最も条件が良い面。

- 階段1（北・ジム/シアター付近）と階段2（南東・対角）はご指定通り。
- 水回り（1階）は西セルに集約し、給排水・動線を1セル内で完結。

## 10. 音響・遮音計画

| 項目 | 内容 |
|---|---|
| 音響コア | ジム（1階）／シアター（2階）を同一フットプリント（6.0×5.0m級）で垂直積層 |
| ジム床 | 浮き床（防振支持、固有振動数8〜10Hz以下を目標）。デッドリフト等の落下エリアはゴムマット＋合板で追加保護 |
| ジム扉 | 遮音仕様（Ts-30〜35目標）、開き戸、ドロップダウンシールで段差レス化。主耐力壁を避けた非耐力壁面に設置 |
| ジム排気 | 専用リターン（RA）を天井に設置し、やや負圧運転 |
| シアター | 最大85dB想定。浮き床＋二重壁。前室（緩衝廊下4畳）を二重扉化し低音漏れを追加抑制 |
| 中間スラブ | ジム／シアター間の1枚（防振吊り天井＋吸音を併用） |
| ジムの立地優位性 | 1階・地盤面直上のため、落下衝撃は基礎経由で地盤に逃げる（2階配置時より有利） |

## 11. 未確定・別途検討が必要な項目

1. **正確な敷地実測図・境界確定**（特に北側水路との境界、42条2項道路の該当有無と正確な後退量）
2. **地盤調査（ボーリング）**および基礎形式（直接基礎か杭基礎か）の確定
3. **角地緩和の適用可否**（建蔽率60%→70%の可能性）の行政照会
4. **2階の窓仕様**（面積・排煙方式）の個別決定
5. **駐車場棟（ソーラーカーポート）の構造形式**および正確な規模・配置（駐車3台を西側帯に想定。現況敷地700m²に対し試算で約18m²不足のため、車路・駐車奥行の圧縮または配置の再検討が必要）
6. **擁壁・塀の構造計算**（がけ条例対応、工作物確認申請）
7. **水路（法定外公共物）の占用許可・境界確定**の行政手続き
8. **ハザードマップのピンポイント数値確認**（現時点は目視判読ベース）
9. **構造設計者による壁量・スパン・耐震壁位置の最終照査**
