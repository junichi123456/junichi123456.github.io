# 資産運用試算の再評価（取得費と取り崩しモンテカルロ）

金額は 2026 年の円の実質値（税込、万円）。【確定】【推定】【仮定】【要確認】は根拠の強さ。計算は `finance/portfolio_mc.py`（N=100,000、seed=20261125、共通乱数）で再現できる。

## 結論

1. **取得費は施主試算の想定と桁が違う。** 施主の結果3は「家予算 50年で約5,000万、上限 約1.5億」。既存 docs から積むと建物側だけで **約3.43億（低）／4.40億（中）／5.65億（高）**。土地が未取得ならさらに約3.3億〜4.8億かかり、合計は 6.7億〜10.5億（高ケースは 10億 − 手元 3,000万を超えて不成立）。
2. 運用の元本は 9.7億ではなく、**10億 − 取得費 − 手元現金 3,000万 ＝ 6.27億（低）／5.30億（中）／4.05億（高）**（土地取得済み）。
3. 生活費に建物の維持費（修繕積立 164.4万、保険 35万、光熱 10万、固定資産税はケース連動）を足すと基準支出は中ケースで年 約1,089万。初年度の取り崩し率は 低 1.6%／中 2.1%／高 2.9%（施主案は 1.86%）。
4. **主表（株100%・バッファなし・実質一定 R0）の50年枯渇確率は μ4% で 低 12.7%／中 23.3%／高 46.8%。** 施主の「9〜30%」（9.7億・1,800万）は、取得費を差し引かない前提でしか成り立たない。
5. 改善は債券比率とガードレール（R3）で大きい。中ケース・μ4% で 50年枯渇は 23.3% → 9.7%（債券40%・R3）。ただし削れるのは生活費 D（支出の約1/3）だけで、効果には上限がある。
6. 国保の「上限 約106万」は、特定口座（源泉徴収あり）の申告不要にすれば悲観に寄る可能性が高い（感度 A2。金融所得を保険料に反映する案があり【要確認】）。

## 3. モデルの前提

### 3.1 乱数と資産

N=100,000、T=50年（年次）、`numpy.random.default_rng(20261125)`。全ケースで同じ乱数（共通乱数）。株・債券・インフレの攪乱をコレスキー分解で相関づける。

| 系列 | 式 | 既定値 |
|---|---|---|
| インフレ | i_t = 0.02 + 0.5(i_(t−1) − 0.02) + 0.015·e_i | 施主どおり。sd 1.5% は攪乱の sd |
| 株（実質・算術） | r_s = μ + σ·e_s − 0.002 | σ=16%、μ は 3・4・5% |
| 株の名目 | (1+r_s)(1+i_t) − 1 | |
| 債券（実質） | r_b = 0.0075 + 0.06·e_b | 実質 0.75%、σ 6%【仮定】 |
| 現金・短期債 | 名目 年1.5% 固定 | 実質は約 −0.5%【仮定】 |
| 相関（既定） | 株‐債券 0.1、株‐インフレ 0.0、債券‐インフレ −0.5 | |
| 感度 | スタグフレーション（株‐インフレ −0.4）、ファットテール（t df5×√(3/5)）、σ=18% | |

### 3.2 口座と税

- 口座は課税株・NISA・債券・現金。名目で保有し評価時に CPI で割る。開始時 W0 ＝ 10億 − 取得費 − 3,000（万円）。NISA は 1,800万を t=0 に入れる（年 360万上限は無視で楽観側）。現金バッファは k年 × 初年度支出。
- 課税株の売却: 含み益の割合 g に対し、手取り x のための売却額は x/(1 − 0.20315g)。簿価は売却額に比例して減らす（総平均法）。損失繰越なし。
- 債券・現金の利子: 名目利回りが正の分に 20.315% を毎年課税（評価損益は非課税の簡略化）。
- 取り崩し順: 現金 → （前年の株の名目リターン ≥ 0 なら株、< 0 なら債券）→ 残りの債券・株 → NISA。
- バッファ補充: 前年の株が ≥ 0 なら株を売って現金を k年分に戻す。株比率が目標＋5pt を超えたら目標まで売って債券を買う（売却益は課税）。
- 枯渇: その年の手取り支出を総資産で払えない年。以降は資産 0。

### 3.4 取り崩し規則

| ID | 規則 |
|---|---|
| R0 | 実質一定 |
| R1 | 施主再現用: 支出全体を名目で max(i_t + 0.2%, 0) ずつ増やす |
| R2 | 前年のポートフォリオの名目リターンが負なら D のインフレ調整を止める（取り戻しなし）。D の下限は基準の 60% |
| R3 | 実質総資産が W0 の 80% 未満なら基準支出合計の 10% を D から削る。60% 未満なら 20%。90% 以上で戻す |
| R4 | ガイトン・クリンガー型: 取り崩し率が初年度の 1.2倍超なら D×0.9、0.8倍未満なら ×1.1（基準の 120% まで）。D の下限は基準の 50% |

**削れるのは D だけで、D は支出の約1/3。ガードレールの効果には上限がある**（R3 の最大削減は基準合計の 20%、D の約 60%）。

## 5. 推奨案

G2（取得費 中・μ4%・R3）で、50年枯渇確率と最低支出比 10% 点を合わせて見ると、**債券 40%・バッファ 0年・R3** が最良（50年枯渇 9.7%、30年枯渇 0.1%、最低支出比 10%点 0.80）。最低支出比は R3 の構造（D を最大 20% 削る）でどの構成もほぼ 0.80 で、差は枯渇確率に出る。

- 仕様の例（バッファ2年＋債券20%＋R3）は μ4% で 50年枯渇 13.1%。本モデルではバッファ年数の効果は小さく（補充の売却に課税される分、むしろ僅かに悪化）、効くのは債券比率とガードレール。
- μ3% では推奨構成でも 50年枯渇 16.9%。μ3%＋スタグフレーションでは 17.3%（30年 0.2%）。μ4% の推奨構成でも約 10% で、「50年で 10% 以下」は境界線。
- 債券 40% は実質 0.75%・σ6% の仮定に依存する【仮定】。債券の期待が低ければ効果は小さくなる。
- 取得費を下げる（外構・蓄電池・設計の見直し）ことが最も効く。低ケースなら株100%・R3 でも μ4% で 7.1%。

## 7. 要確認（施主へ）

1. 土地は取得済みか（brief 30章の「施主所有のまま」から推定）。店舗の解体・土壌調査は済んでいるか。
2. 建築費の見積もり（2.5〜3.0億は評価額からの逆算）。外構・蓄電池・設計監理が本体に含まれるか。
3. 「10億」が税引後の金融資産だけか。手元現金 3,000万と仮住まい費用の扱い。
4. 世帯人数と年齢（国民年金の人数、国保の介護分、65歳からの公的年金、75歳からの後期高齢者医療）。
5. 取り崩しを特定口座（源泉徴収あり）の申告不要で行う方針か。ほかの所得はあるか。
6. 生活費月30万に、車・旅行・医療・家電の更新が入っているか。
7. 建築中の支払い時期（分割払いなら、その間の運用の扱い）。
8. 築50年の大規模改修・建替えを計画に含めるか（今回は修繕積立の継続だけ）。
