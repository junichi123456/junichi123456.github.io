## 3. モデルの前提

### 3.1 乱数と資産

N=100,000、T=50年（年次）、`numpy.random.default_rng(20261125)`。全ケースで同じ乱数（共通乱数）。株・債券・インフレの攪乱をコレスキー分解で相関づける。

| 系列 | 式 | 既定値 |
|---|---|---|
| インフレ | i_t = 0.02 + 0.5(i_(t−1) − 0.02) + 0.015·e_i | 施主どおり。sd 1.5% は攪乱の sd |
| 株（実質・算術） | r_s = μ + σ·e_s − 0.002 | σ=16%、μ は 3・4・5% |
| 株の名目 | (1+r_s)(1+i_t) − 1 | |
| 債券（実質） | r_b = 0.0075 + 0.06·e_b | 実質 0.75%、σ 6%【仮定】 |

### 3.2 口座と税

- 口座は課税株・NISA・債券・現金。名目で保有し評価時に CPI で割る。開始時 W0 ＝ 10億 − 取得費 − 3,000 − 建築期間 P（万円）。主ケースは建物・土地・P の合計を引く（1.6 章）。NISA は 1,800万を t=0 に入れる（年 360万上限は無視で楽観側）。現金バッファは k年 × 初年度支出。
- 課税株の売却: 含み益の割合 g に対し、手取り x のための売却額は x/(1 − 0.20315g)。簿価は売却額に比例して減らす（総平均法）。損失繰越なし。
- 債券・現金の利子: 名目利回りが正の分に 20.315% を毎年課税（評価損益は非課税の簡略化）。
- 取り崩し順: 現金 → （前年の株の名目リターン ≥ 0 なら株、< 0 なら債券）→ 残りの債券・株 → NISA。
- バッファ補充: 前年の株が ≥ 0 なら株を売って現金を k年分に戻す。株比率が目標＋5pt を超えたら目標まで売って債券を買う（売却益は課税）。
- 枯渇: その年の手取り支出を総資産で払えない年。以降は資産 0。

## 5. 推奨案

**現設計のまま土地を買うと、50年枯渇 10% 目標は不成立**（4.1 章。最良でも 52%、元本が最大 2.36億）。目標を 50年枯渇 10% 以下とするなら、土地＋建物の合計を **推奨構成（債券40%・R3）で μ4% 約 4.1億**（μ3% 約 3.5億、μ5% 約 4.7億）以下にする（4.3 章）。

- **案1+2 の規模（延床 約300㎡・敷地 約500㎡、総額 約3.1億）なら、推奨構成・R3 で 50年枯渇は μ3% 0.3%／μ4% 0.1%／μ5% 0.0%**。株100%・R0 でも 9.6% / 4.6% / 1.9%（4.2 章）。
- 建物だけの縮小（案1）や土地だけの縮小（案2）、段階導入（案3）では 10% に届かない。土地だけの先行取得（案4）は悪化する。
- 運用元本が小さい（2.4億以下）場合、債券40% は 50年では株100%・R3 より悪い。推奨構成が有利になるのは元本 5.30億 の G2（土地取得済み、4.5 章）で確認した範囲。
- 土地取得済みの場合の推奨構成は、旧版のとおり **債券40%・バッファ0年・R3**（μ4% で 50年枯渇 9.7%）。バッファ年数の効果は小さく、効くのは債券比率とガードレール。債券40% は実質 0.75%・σ6% の仮定に依存する【仮定】。
- 取得費を下げる（外構・蓄電池・設計の見直し、規模縮小）ことが最も効く。

**±3pt 以内で再現できた（合格）。** 条件は「1,800万を売却額として扱い、税はその中に含める（税込み）」。税を 1,800万の外に別途かけると 13.2 / 22.7 / 35.2% で μ4%・3% が +3pt を超えるため、施主の 1,800万は税込みと解釈するのが整合する。R1 の増額に前年のインフレを使うか当年を使うかの差は 0.1pt 未満。主表（4章）の支出は手取りベースで、売却益税は支出の外で別に払う。

- 全ケース（`--grid all`）N=10万で約7分（旧グリッド約3分＋土地関連 約4分、numpy のみ）。旧グリッドの結果は bce9988 と完全に一致する（秒を除く）。`finance/test_portfolio_mc.py` は N=5,000。

- 推奨構成の選択基準: μ4%・R3 の G2 から「50年枯渇% ＋ 0.5×(1 − 最低支出比10%点)×100」が最小のもの。
